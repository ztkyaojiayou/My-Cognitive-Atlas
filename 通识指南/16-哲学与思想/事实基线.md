## 一、本模块的头号禁令：**不写年份**

哲学卡片几乎不需要精确年份。"古希腊""先秦""18 世纪"这种粒度足够，
而"柏拉图生于公元前 427 年""康德《纯粹理性批判》出版于 1781 年"这类数字，**写错就是硬伤，写对也不增值**。

**规则：本模块所有卡片，一律不写具体年份与生卒年。**

需要交代时代时，用**时代与相对顺序**代替：

- ✅「在柏拉图笔下，苏格拉底……」
- ❌「公元前 399 年，苏格拉底被判处死刑」

- ✅「康德之后的德国观念论者……」
- ❌「1781 年之后，德国观念论……」

---

## 二、本模块的第二号禁令：**不给学派贴单一标签**

哲学写作最常见的错误不是年份错，是**把一个人的立场说成整个学派的立场**，
或者把某个流派压缩成一个听起来顺口的标签。

**禁止写法：**

- ❌「唯物主义者都认为意识不重要」
- ❌「经验论者否认理性的作用」
- ❌「存在主义者认为人生没有意义」
- ❌「儒家主张人应该无条件服从权威」

**允许写法：**

- ✅「在这一支传统里，比较有代表性的说法是……但它内部也有不同意见」
- ✅「把 X 归到这个名下的人未必同意彼此的其他观点」

> 判据：**如果你的句子能改写成"某派 = 某句口号"，那它多半是错的或过度简化的。**

## 三、可写的核心命题（归属白名单）

**以下每条都可以直接写，超出这张表的哲学家→观点的对应，一律不写。**

### 古希腊与古典

| 命题 / 概念 | 归属 | 备注 |
|---|---|---|
| 洞穴寓言（被锁住的囚徒只看见影子，出洞的人才见到真实） | 柏拉图《理想国》 | 讲感官世界与真实世界之别，也可解作"教育即转向" |
| 理念论：具体事物分有理念 | 柏拉图 | 与洞穴寓言同属一支 |
| 苏格拉底之死（受审、饮鸩） | 见柏拉图《申辩篇》等对话 | 苏格拉底本人未著书，其思想主要通过他人记述传世 |
| 「人是万物的尺度」 | 普罗泰戈拉 | 常被引作相对主义的早期源头 |
| 四因说：质料、形式、动力、目的 | 亚里士多德 | 追问"一个事物为什么是它"的四种回答方式 |
| 三段论 | 亚里士多德 | 形式逻辑的早期系统化 |
| 德性论：核心是**实践智慧**与**中道**；问的不是单个行为对不对，是做事的人在成为什么样的人 | 亚里士多德 | 中道不是折中，是在具体处境里找到恰当的那一点 |
| 「吾爱吾师，吾更爱真理」 | 归于亚里士多德 | 中文语境广为流传，原话出自他人记述的转述 |

### 现代伦理与政治哲学

| 命题 / 概念 | 归属 | 备注 |
|---|---|---|
| 最大幸福原则：判断行为看它增进还是减少相关者的幸福 | 边沁、密尔（功利主义） | 功利主义**要求**把所有人的幸福算进来，不是"自私自利" |
| 伤害原则：干涉他人自由的唯一正当理由是防止其伤害他人 | 密尔《论自由》 | |
| 无知之幕：在不知道自己会处于何种地位的前提下选择社会规则 | 罗尔斯《正义论》 | 思想实验，不是历史描述 |
| 两条正义原则（平等的自由优先；不平等只有在最有利于最不利者时才被允许） | 罗尔斯 | 后者即「差异原则」 |
| 持有正义：只要获取与转让是正当的，结果无论多不均都不需要再矫正；国家只做「守夜人」（防暴力、防盗窃、保障契约履行） | 诺齐克《无政府、国家与乌托邦》 | 与罗尔斯构成正面对立 |
| 电车难题：改道牺牲一人救五人，是否与直接杀一人等价 | 由福特（Philippa Foot）提出，经汤姆森（Judith Jarvis Thomson）扩展 | 用来暴露后果论与义务论的冲突 |

## 四、可写的概念区分（这是本模块最值钱的一组）

| 常被混淆 | 区别 |
|---|---|
| **唯物 vs 唯心** | 争的是"什么是第一性的"，不是"谁更看重物质"。把唯心主义理解成"心想事成"是最典型的误读 |
| **本体论 vs 认识论** | "有什么" vs "我们怎么知道有什么"。混淆这两者会让很多争论变成各说各话 |
| **理性论 vs 讲道理** | rationalism 指"知识有独立于经验的来源"，不是说一个人是否理性 |
| **经验论 vs 经验丰富** | empiricism 指"一切知识来自经验"，不是"人生阅历多" |
| **功利主义 vs 自私** | 功利主义要求把**所有受影响者**的幸福都算进去，与利己主义相反 |
| **决定论 vs 宿命论** | 决定论说"事件由前因决定"；宿命论说"无论你怎么做结果都一样"。后者否定了行动的意义，前者不一定 |
| **相容论 vs 硬决定论** | 相容论认为决定论成立时自由仍然有意义；硬决定论认为"自由"是一种幻觉 |
| **不可知论 vs 无神论** | 不可知论说"无法知道"；无神论说"不存在"。这两者是可以同时反对的立场 |
| **存在主义 vs 虚无主义** | 存在主义承认没有预先给定的意义，但主张人要自己承担创造意义；虚无主义停在后半步 |
| **儒家 / 儒学 / 儒教** | 学术传统 / 思想体系 / 制度化宗教形态，三者不能混用 |
| **禅宗 vs 佛教** | 禅宗是佛教在中国形成的宗派之一，不是佛教的全部 |
| **相对主义 vs 宽容** | 相对主义是一种关于真理或价值的主张；宽容是一种态度。前者不必然导致后者 |
| **客观唯心 vs 主观唯心** | 这是一组**分类词**，不是褒贬词。前者把根据放在个物之外（理念、绝对精神一类，柏拉图与黑格尔常被归入），后者放在「被感知」上（贝克莱）。可以用它分类，不能拿它代替论证 |
| **自由意志论（形而上学）vs 自由至上主义（政治）** | 英文同为 libertarianism，含义完全不同：前者主张存在非决定的自由选择，后者主张最小政府。中译常混用 |
| **「先天」vs「天生」** | 「先天」(a priori) 指证成方式不依赖经验；「天生」(innate) 指出生即具备。两个不同的概念，「先天综合判断」里的「先天」是前一个意思 |

## 五、本模块「不确定就别写」清单

**以下一律不写：**

- ❌ 哲学家的生卒年、著作的出版年份
- ❌ 「某位哲学家一生如何如何」的传记细节
- ❌ 具体的历史事件年份（包括思想史上的转折点）
- ❌ 某位哲学家"影响了后世多少人/多少国家"这类量的断言
- ❌ 把某位思想家的立场直接说成"某某主义的定义"
- ❌ 任何"东方 vs 西方"的整体性对举（"西方重分析，东方重直觉"这类句子）
- ❌ 对现实政治制度、政策、人物的评价
- ❌ 宗教教义的真伪判断（只描述其内容与功能）
- ❌ 「某某说过……」的名言（**除非在上面的白名单里**——假托名言是本模块第一大坑）

> ⚠️ 特别提醒：中文互联网上流传的"哲学家名言"有相当比例是伪造或张冠李戴的。
> **没在白名单里的引语，一句都不要写。**

## 六、写作提醒

1. **这个模块讲"问题与代价"，不讲"结论"。** 每提出一个立场，最好的写法是紧接着写"它的对手会从哪里攻它"。
2. **涉及宗教与政治思想时，只描述内容与功能，不做真伪判断，不褒贬。**
3. **中国思想部分要当思想写，不要当文化符号写。** 避免"博大精深""智慧结晶"这类空词。
4. **每个术语后面必须跟一句人话。** 术语本身不构成解释。
5. **不要把哲学史当主线。** 卡片的主角是"问题"，哲学家只是回答问题的人。

## 七、资料来源分级（本模块）

| 级别 | 对应 |
|---|---|
| A | 哲学原典、权威哲学百科（如 Stanford Encyclopedia of Philosophy）、学术专著 |
| B | 通行的哲学史教材、专业译本的译者注 |
| C | 优质通识读物、纪录片、大学公开课 |

> D 级在本模块的危害远大于其他模块：**伪造的名言比错误的年份更难被发现，因为它读起来永远像真的。**
