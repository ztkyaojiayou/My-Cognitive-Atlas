# 政治与国际关系 · 事实基线

> **卡片写作时只引用本文件，不自行生成硬事实。**
> 见 `../事实基线规范.md`。

---

## 一、本模块的头号禁令：**只描述机制，不评现实**

这是全项目最敏感的一个模块。以下三类内容**一律不许出现**：

### 1.1 不许给现实制度、政策、人物排优劣

- ❌「某国的选举制度不公平」
- ❌「议会制比总统制更稳定」
- ❌「这项政策是失败的」
- ✅「单一选区相对多数制下，小党很难拿到席位——分散的选票在每个选区都不占第一」
- ✅「议会制里行政首脑来自议会多数，行政与立法通常不对立；总统制里两者分别选举产生，可能各有各的授权。这是两种不同的安排，代价也不同」

> 判据：**把一句话里的"更/不如/失败/成功"划掉，如果剩下的部分不成立，那它就是在评价。**

### 1.2 不许给国家、群体贴整体标签

- ❌「某国就是……」「某国人就是……」
- ❌「这类体制下的人都会……」
- ✅「有的制度把最终决定权放在某处，这会让……变难、……变容易」

### 1.3 不预测未来

- ❌「照这个趋势，将来会……」
- ❌「这迟早会导致……」

> **本模块的定位是"让人看懂机制"，不是"替人下判断"。**
> 评价需要掌握具体情况并承担判断责任；卡片只保证读者在评价之前，不会连它是怎么运转的都搞错。

---

## 二、本模块的第二号禁令：**不写具体数字**

- ❌ 任何票数、席位数、得票率
- ❌ 任何任期年限、机构人数、预算规模
- ❌ 任何年份、条约编号、文件编号
- ❌ 任何国家的具体行政区划数量

需要表达时用**关系与结构**：

- ✅「任期长度是制度设计里的一个变量：短则换人频繁、政策延续性弱，长则约束变松」
- ❌「某国总统任期四年」

---

## 三、本模块的第三号禁令：**不给"民主／非民主"当二分法用**

把政体分成两类，是一种粗糙但有传播力的说法。学界主流的测量方式更接近**连续谱**：用多个维度打分，而不是划线分两边。

- ❌「民主国家如何如何」「非民主国家如何如何」——这种句子一律不写
- ✅「不同政体在'权力来源''对权力的约束''更替方式'这几个维度上位置不同，很多国家在中间地带」
- ✅「二分法好用、好传播，但它在边界上会失真——而边界上的国家相当多」

## 四、可写的核心概念（白名单）

### 4.1 政治与权力

| 概念 | 可写内容 |
|---|---|
| **政治的定义** | 一群人利益不一致、又没有共同上级时，怎么做共同决定的过程。核心是**分配**：谁得到什么、什么时候、怎么得到 |
| **政治的成立条件** | 三个条件同时具备时政治必然出现：**稀缺**（资源不够分）、**冲突**（各方诉求不一致，且往往各自都有正当理由）、**必须共同决定**（无法各干各的）。它不需要谁设计，凑齐了就长出来 |
| **集体决策的三方取舍** | **参与范围**（谁的声音被听见）、**决策速度**、**可修正性**。三者此消彼长——要尽量都听见就得花时间，要快必然有人没被问到，要能修正就得留出反复的空间。不存在同时最优，任何安排都是在这三条上选了一个位置 |
| 权力 | 让别人做他原本不会做的事的能力。注意：**不一定是强迫**——也可以是让他觉得这么做对他有利 |
| 权威 | 被认为**正当**的权力。区别：权力靠"能做到"，权威靠"被认为应该" |
| 强制 / 说服 / 诱导 | 三种运作方式，多数场合同时使用，而非只取其一 |
| 三种合法性来源（韦伯） | 传统（历来如此）、魅力（这个人身上）、法理（规则规定）。现实中常是几者的混合 |
| 「合法」的两种意思 | 一是合乎本国的实在法；二是被民众认作正当。这两件事可以分离，不是一回事 |

### 4.2 国家与政体

| 概念 | 可写内容 |
|---|---|
| 国家的构成 | 常用的四要素说法：领土、人口、政府、主权。它是**有限且排他的**——一块地只归一个国家管 |
| 主权 | 对内最高、对外独立。它本身是一束可以分割与让渡的权利，不是不可分的一块 |
| 政体分类的三个常见维度 | 谁掌握最终决定权；权力如何获得（继承、选举、任命等）；权力如何被约束 |
| 交叉分类 | **议会制／总统制是"行政与立法的关系"这个维度的分类；联邦制／单一制是"纵向权力"这个维度的分类。两者可以交叉，不是并列的标签** |
| 议会制 | 行政首脑由议会多数产生，因此行政与立法通常不对立；代价是行政首脑的稳定性取决于联盟或党内的稳定 |
| 总统制 | 行政与立法分别由选举产生，各有各的授权；代价是两者不同属一个多数党时容易僵局 |
| 半总统制 | 兼具两者要素，权力如何分配取决于具体的制度条文与政党格局 |
| 一党制与多党制 | 说的是**政党竞争的结构**，不是政体的全部 |
| 联邦制与单一制 | 说的是**纵向权力的分配**。联邦制下地方权限由宪法规定，不能由中央单方面收回 |
| 政体分类的局限 | 同一名称下的国家，实际运转可以差很远。**名称是坐标，不是结论** |

### 4.3 分权与制衡

| 概念 | 可写内容 |
|---|---|
| 横向分权 | 立法、行政、司法。目的**不是效率，是防止任何一方滥用** |
| 纵向分权 | 中央与地方。理由通常是"离得近的人更了解本地情况"与"防止权力集中"两条 |
| 制衡的代价 | 效率下降、容易僵局、责任归属模糊（出了问题找不到谁负责） |
| 委托—代理 | 委托人（选民、上级）与代理人（官员、代表）利益不一致且有信息差，因此需要监督与激励 |
| 独立机构 | 部分职能被有意地与政治周期隔开，代价是**它为这种独立性付出的合法性成本** |

### 4.4 选举制度与政党

| 概念 | 可写内容 |
|---|---|
| 选举制度的两种基本类型 | **多数决**（每个选区选出胜者，常见形式是相对多数）与**比例代表制**（按得票比例分配席位）；还有大量混合制 |
| 多数决的机制后果 | 议会席位数与得票率容易脱节；**小党很难生存**——分散选票在每个选区都不占第一 |
| 比例代表制的机制后果 | 席位与得票更接近；但**政党容易变多**，组阁需要谈判，责任归属变模糊 |
| 迪韦尔热定律 | 单一选区相对多数倾向产生两党格局，比例代表制倾向产生多党格局。它是**倾向性规律，不是铁律**——有反例（地区性政党、优惠投票等） |
| 战略投票 | 选民为了不浪费票，会投给"有希望赢的大党"而不是最想要的那个。**规则塑造行为**，这是选举制度影响结果的深层机制 |
| 选区划分 | 划法不同，同样的选票会得到不同席位。因此多数国家设有相对独立的划界程序 |
| 政党的功能 | 聚合散乱的利益、组织选举、形成政府、连接社会与国家 |
| 利益集团 | 不直接推候选人的组织化利益表达；与政党的区别在于**它要的是影响，不是执政** |

### 4.5 官僚制与政策

| 概念 | 可写内容 |
|---|---|
| 官僚制的特征（韦伯） | 层级、分工、规则化、非人格化、职业化、留痕 |
| 它为什么被设计成这样 | 为了让决定**可预期、可追责、不因人而异**。它最初是对"看人下菜碟"的纠偏 |
| 它的代价 | 目标置换（把遵守流程当成目的本身）、繁文缛节、对非常规问题反应慢 |
| 街头官僚 | 一线执行者拥有大量实际裁量权。**政策在末端会被执行者重新解释**，这不是执行者坏，是规则无法覆盖全部情境 |
| 执行偏差 | 政策从纸面到落地必然变形，原因包括：目标模糊、资源不足、多方博弈、考核指标代替了目标 |
| 集体行动困境 | 每个人理性地不付出，结果所有人受损。搭便车是它的典型形态 |
| 议程设置 | 问题多而注意力有限。**让一个问题进入议程，本身就是一种权力** |
| 政策窗口 | 问题、方案、政治条件三者同时具备时，改变才可能发生 |

### 4.6 国际关系

| 概念 | 可写内容 |
|---|---|
| 无政府状态 | **指没有高于国家的共同权威，不是"混乱"**。这是国际关系与国内政治最根本的区别 |
| 自助体系 | 没有警察，因此国家最终只能靠自己保障安全。这决定了它们的行为逻辑 |
| 均势 | 当一方力量过强时，其他方有联合制衡的倾向。它是**一种倾向，不是自动稳定器** |
| 联盟 | 应对共同威胁的临时或长期结合。威胁消失，联盟常常随之松动 |
| 国际组织 | 靠成员国授权运作，**没有超国家的强制执行权**。它的作用在于降低交易成本、提供信息与场所 |
| 国际法 | 没有世界警察，靠互惠、声誉、对等报复这些机制起作用。它约束力有限，但不是无效 |
| 国内类比为什么失效 | 国内的"法律——警察——裁判"三件套，在国际层面缺了中间那一件 |
| 战争的层次解释 | 体系层（力量分布）、国家层（制度与国内政治）、个人层（决策者认知）。**单一层次解释几乎总是漏** |
| 安全困境 | 一方为自保而增强军力，被对方读成威胁，对方也增强——**双方都没有恶意，结果却螺旋上升** |
| 重复博弈 | 各方还要继续打交道时，单次占便宜会抬高后续成本。**合作不完全靠善意，靠的是"还要再见"** |
| 议题联结 | 在一个议题上让步、换取另一个议题上的回报，让原本各自无解的谈判变得可能 |
| 民主和平论 | 统计上，民主国家之间发生战争的情况少见。但**因果解释存在争论**（是制度使然，还是这些国家之间的其他条件使然）。**写这一条必须带"有争议"，不可写成定论** |

## 五、易混概念对照（本模块最值钱的一组）

| 常被混淆 | 区别 |
|---|---|
| **权力 vs 权威** | 前者是"能做到"，后者是"被认为应该"。可以有权无威，也可以有威无权 |
| **合法 vs 合乎法律** | 「合法」在中文里同时指"符合实在法"和"被认作正当"，这两件事可以分离 |
| **国家 vs 政府 vs 政权** | 国家是持久的那个框架；政府是当下的执政班子；政权更多指统治方式与制度总体 |
| **政体 vs 政策** | 前者是权力怎么组织，后者是具体做什么。**对政策的评价不等于对政体的评价** |
| **议会制 vs 总统制** | 分类依据是**行政与立法的关系**，不是"有没有总统"。有的国家有总统但仍是议会制 |
| **联邦制 vs 单一制** | 分类依据是**纵向权力**。它与上面那组可以交叉，不是并列选项 |
| **民主 vs 选举** | 选举是其中一个机制，不等于全部。把两者等同，会让分类失去分辨力 |
| **多党制 vs 不稳定** | 政党数量与政府稳定性相关，但不是同一件事——联盟结构、选举周期都在起作用 |
| **无政府状态 vs 混乱** | 前者指"没有共同上级"，是一种结构；后者是对状态的描述。国际体系是无政府状态，但不等于无序 |
| **国际组织 vs 世界政府** | 前者是成员国授权下的协调机制；后者意味着主权让渡。这两者差距很大 |
| **政治 vs 行政** | 前者处理"该不该做、谁的诉求优先"，后者处理"怎么执行" |
| **一致同意 vs 多数决定** | 前者保护少数但容易瘫痪，后者效率高但可能压过少数。这是所有集体决策绕不开的取舍 |

## 六、本模块「不确定就别写」清单

**以下一律不写：**

- ❌ 任何国家的制度优劣排序、任何"更好／更差"的判断
- ❌ 对现实政策、事件、政治人物的评价、预测、动机揣测
- ❌ 「某国就是……」「某国人就是……」式整体断言
- ❌ 任何具体数字：票数、席位、得票率、任期、机构规模、年份、条约编号
- ❌ 把政体分成"民主／非民主"两类的二分表述
- ❌ 「某制度必然导致某结果」式决定论
- ❌ 把民主和平论写成定论
- ❌ 任何"照这个趋势将来会……"的预测
- ❌ 对当下正在进行的国际争端的立场表态
- ❌ 涉及中国时：**只写可核实的制度安排与个体处境，不做评价、不与他国作优劣比较**

## 七、写作提醒

1. **每讲一种制度安排，必须同时写出它的代价。** 只讲优点不讲代价，就是在变相评价。
2. **能写"有的国家"就不点名。** 点名时只写可核实的制度事实（如"某国的首相来自议会多数党"），并说明它在该类制度中的特殊性。
3. **不写"应该"。** 这个模块讲"是什么、为什么这样运转"，不讲"应该怎样"。
4. **多用"倾向""通常""在什么条件下"，少用"必然""一定"。** 政治学里几乎没有铁律。
5. **区分描述与分析。** 描述制度安排是安全的；推断动机是危险的。

## 八、资料来源分级（本模块）

| 级别 | 对应 |
|---|---|
| A | 各国宪法与官方文件、国际组织公开文件、同行评审的政治学文献 |
| B | 通行比较政治学教科书、权威百科、专业机构发布的政体测量数据集说明 |
| C | 优质新闻报道、纪录片、当事人回忆 |
| D | 立场鲜明的评论、自媒体时政分析 | → **本模块危害最大，一律不作依据** |

> 这个模块的 D 级内容有一个特征：**它往往不写错事实，而是把"某一种解释"当成"唯一解释"。**
> 判断的办法不是查它的事实对不对，是问：**它有没有交代另一种解释，以及那种解释为什么不够？**
