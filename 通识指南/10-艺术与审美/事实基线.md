# 艺术与审美 · 事实基线

> **卡片写作时只引用本文件，不自行生成硬事实。**
> 见 `../事实基线规范.md`。

---

## 一、本模块的头号禁令：**不评价作品高下**

- ❌「这是杰作」「这幅比那幅好」「大师之作」
- ❌ 任何对具体作品、艺术家、流派的价值排序
- ❌ 「怎么看懂艺术」这类指导
- ✅「一件东西成为'艺术品'，需要它进入一套装置：展览、解释、流通」

**这一条不是回避，是分工。** 「美是主观还是客观」「为什么看不懂的画也能是杰作」「审美能否训练」——**这些判断层面的问题在 `自我探索` 6.2 视觉艺术里已经讲过，那里讲得更细。**

本模块只讲**系统怎么运转**。若卡片开始论证"什么算好"，它与 6.2 就重复了。

---

## 二、本模块的第二号禁令：**不写价格与市场数据**

- ❌ 任何拍卖成交额、涨幅、指数、艺术家排名
- ❌ 任何作品的市场表现、投资回报
- ❌ 任何"某类作品正在升值"

---

## 三、本模块的第三号禁令：**不写精确年份**

艺术史的分期本身就有争议，写死了就是假精确。

- ✅「文艺复兴时期」「19 世纪」「20 世纪上半叶」
- ❌「某年，某人画了某画」「某年某机构成立」

需要交代先后时，用**相对顺序**：「在摄影出现之后」「在学院制度确立之后」。

---

## 四、本模块的第四号禁令：**不预测，不评价制度**

- ❌ 艺术趋势预测（「未来艺术会……」）
- ❌ 对任何国家的文化政策、艺术体制的优劣评价
- ❌ 对具体展览、美术馆的推荐与评价

## 五、可写的概念与机制（白名单）

### 5.1 艺术作为一套制度

| 概念 | 可写内容 |
|---|---|
| **三元结构** | **创作者**、**作品**、**观者**。三者缺一，那件事就不成立——没有人做、没有人看，就没有"艺术"这回事 |
| **制度层** | 支撑三元的四样东西：**机构**（博物馆、画廊、学院）、**市场**、**批评与阐释**、**教育**。**它们共同决定什么被看见、什么被叫作艺术** |
| **艺术界** | 由丹托（Arthur Danto）提出的思路：一件东西成为艺术品，需要**艺术界的理论氛围能够接纳它**。**同一个物，在一种氛围里是垃圾，在另一种里是作品** |
| **分界的争论** | 「什么算艺术」有两类答案：**本质论**（艺术有某种内在属性）与**制度论**（艺术由制度授予）。**这不是已经解决的问题**，卡片只能摆出两边 |
| **它的代价** | 制度让艺术可以被生产、流通、保存，**代价是它同时也决定了什么进不来**——没有被这套装置接住的东西，往往连"被讨论"的机会都没有 |

### 5.2 门类

| 门类 | 可写内容 |
|---|---|
| 绘画 | 在二维平面上制造图像。**它的媒介特性是"平面"**——这一点后来成了现代主义的关键 |
| 雕塑 | 三维实体。**减法**（雕刻，从材料里去掉）与**加法**（塑造，把材料堆起来）是两条不同的路径 |
| 建筑 | 既是艺术也是工程。**它有使用功能**，这是它与其它门类最根本的不同——**要住人，就不能只考虑看** |
| 版画 | **复数性的原作**：它不是"复制品"，是从版上印出来的多份原作。这个性质在艺术史上很特殊 |
| 摄影 | 机械或化学成像。**"谁是作者"这个问题在它身上一直有争议**——按下快门的人，还是设计机器的人 |
| 装置 | 占据空间的组合。**它把"观看"变成了"身处其中"** |
| 行为 | 以身体与时间为媒介。**它不可保存**，只能靠记录与文献进入系统 |
| **媒介特性的意义** | 每个门类能做的事不一样。**这不是技术限制，是它成立的理由**——一种艺术之所以独立存在，往往是因为它有别的门类做不到的东西 |

### 5.3 西方分期（只讲结构）

| 段落 | 可写内容 |
|---|---|
| 古代 | 埃及、希腊、罗马。**埃及的图像服务于秩序与永恒，希腊转向对人的观察**——两种目标造就了两种"像不像"的标准 |
| 中世纪 | 宗教主导。**图像的职能是教化与唤起**，不是再现现实——所以"画得像不像"不是它的评价标准 |
| **文艺复兴** | 三个转折：**透视法**（在平面上制造深度）、**解剖研究**（对人体结构的实测）、以及**艺术家地位的变化**——从工匠上升为创造者。**这三件事共同改写了"画家是什么人"** |
| 巴洛克与洛可可 | 前者强调动势与戏剧性，后者转向轻盈与装饰。**两者都是"给谁看"变化的结果**——宫廷趣味的更替 |
| 19 世纪 | 学院体系此时已经主导（学院作为制度在更早的世纪就已确立），新古典、浪漫主义、写实主义、印象派依次与它对峙。**这一段的主线是"谁有资格定义正确"** |
| **现代主义** | 从再现转向形式自省。**核心问题变成"这种媒介自己能做什么"**，而不是"它能模仿什么" |
| 当代 | 观念、跨媒介、全球化。**"什么算艺术"这个问题被作品本身反复提出** |

> ⚠️ **这套分段是西方的，不是普世的。** 它好用在于便于指认，不好用在它把连续的变化切成了块，而且只覆盖了一条线。

### 5.4 中国艺术

| 概念 | 可写内容 |
|---|---|
| 书画同源 | 书写与绘画共用一套工具与笔法，**两者在中文传统里没有被彻底分开** |
| **文人画** | 创作者多是士人而非职业画师。**这个身份决定了评价标准**："气韵""逸品"被置于"形似"之上——**画得像不像，从来不是最重要的问题** |
| **手卷的观看方式** | 它不是一次看完的。**手卷是逐段展开的**，观者控制节奏，时间被编进了作品里 |
| 山水与"卧游" | 山水画不主要是写生，**它更接近一种可居可游的想象空间**——看画的人在画里走 |
| **留白** | 不是"没画完"，是**让画面留出参与的位置**。空的地方由观者补 |
| 20 世纪的中西碰撞 | 写实体系被引入，与原有的写意传统形成张力。**这不是"先进取代落后"，是两套目标体系的相遇** |

### 5.5 博物馆

| 概念 | 可写内容 |
|---|---|
| 从私藏到公共 | 早期是宫廷与私人的珍宝收藏；**公共博物馆是近代的产物**，与"公众有权观看"这个观念同步出现 |
| **它做的转换** | 一件器物在原来的场景里可能是法器、餐具、礼物；**进了展柜、配上标签和灯光之后，它获得了另一个身份**。这个转换通常不可逆 |
| "框"的四件套 | **展柜、标签、灯光、动线**。这四样共同告诉观者："请把它当作艺术来看" |
| **去语境化** | 物被从原来的场景里移出。**信息因此丢失了一部分，也获得了一部分**——它变得可比较、可研究，代价是原来的用途与意义被剥离 |
| 藏品与展品的区别 | 藏品是"拥有的"，展品是"被呈现的"。**这两个集合不重合**——大量藏品常年不见天日 |

### 5.6 原作与复制

| 概念 | 可写内容 |
|---|---|
| **灵光** | 由本雅明（Walter Benjamin）在《机械复制时代的艺术作品》中提出：**原作在此时此地的独一无二性**。复制品没有这个"此时此地" |
| 复制改变了什么 | 它让更多人能看到，**代价是"它在哪里"这件事不再重要**。而"在哪里"曾经是艺术品很大一部分的分量 |
| **一个反例** | 版画是复数性的原作——**它从一开始就有多份，而每一份都是真的**。所以"原作唯一"不是艺术的定义，只是某些门类的性质 |
| 数字复制 | 进一步：复制不损耗，且可以被无限次再复制。**"原件"这个概念开始变得难以指认** |
| 它的代价 | 复制带来了传播与民主化，**代价是它改变了人们膜拜的对象**——从物本身转向图像 |

### 5.7 市场

| 概念 | 可写内容 |
|---|---|
| 一级与二级 | **一级市场**是画廊代理艺术家、首次出售；**二级市场**是已有作品的再交易（拍卖行是典型）。两者的逻辑不同 |
| **定价的依据** | 艺术品没有一个像成本或收益那样的底盘。**它的价格依赖共识、稀缺与记录**——谁收藏过、在哪些展览出现过、有多少人愿意继续相信它值这个数 |
| "记录"的作用 | 展览史、出版著录、收藏传承——**这些构成了一个物的"履历"**，而履历直接影响它的可交换性 |
| 名声与价格 | 两者互相强化：有名所以贵，贵所以更有名。**这是一个反馈，不是一个测量** |
| 它的代价 | 市场让艺术家可以靠创作活着，**代价是"可销售性"会渗进创作判断**。这不是道德问题，是任何依赖市场的行当共有的结构 |

### 5.8 现代主义

| 概念 | 可写内容 |
|---|---|
| **它要回答的问题** | 摄影接走了"记录现实"这个功能之后，**绘画必须回答一个新问题：如果不需要它来记录，它还有什么用？** |
| 转向 | 从"画什么"转向"怎么画"。**主题让位给方法**——颜色、笔触、平面、边界成了内容本身 |
| **媒介特异性** | 由格林伯格（Clement Greenberg）代表的思路：**每种艺术应当关注自己媒介独有的东西**。绘画独有的是平面，于是它走向平面化 |
| 抽象 | 它不是一个"越来越看不懂"的过程，是**把原本被主题遮住的那一层翻上来** |
| 它的代价 | 现代主义让艺术获得了自主性，**代价是它同时失去了大量的观众**——因为观看它的门槛从"认得出"变成了"了解这套讨论" |

### 5.9 当代艺术

| 概念 | 可写内容 |
|---|---|
| **现成品** | 由杜尚（Marcel Duchamp）开创的思路：**选择一件现成的工业品并把它放进艺术语境，这个"选择"本身成为创作** |
| 观念优先 | 观念艺术的核心是**想法优先于物件**。物可以很简单，甚至不需要存在 |
| **不可收藏的困境** | 行为、临时装置、现场作品无法被收藏。**它们靠照片、录像、文字记录进入系统**——记录成了替身 |
| 它的代价 | 当观念优先，**判断的门槛从"手艺"转向"论述能力"**。这既打开了空间，也让"谁有资格解释"变成了新的权力位置 |
| **"什么算艺术"这个问题的位置** | 在当代，这个问题**不是理论问题，是作品本身在反复提出的问题**。很多作品的意义就在于逼出这一问 |

### 5.10 公共艺术

| 概念 | 可写内容 |
|---|---|
| 纪念碑 | **谁出钱、纪念谁、放在哪**——三个问题定了一件公共作品的性质。**它从来不只是审美决定** |
| 公共空间的艺术 | 它有一个额外的约束：**使用者不是自愿的观众**。私人美术馆里你可以不去，广场上的雕塑你绕不开 |
| **近年对纪念物的重新审视** | 一些纪念碑被重新讨论：纪念的对象、叙述的角度、以及"保留还是移除"。**这反映的不是审美变化，是"我们想记住什么"的变化** |
| 它的代价 | 公共艺术让艺术进入日常，**代价是它必须在多方之间妥协**——出资方、使用者、管理者、以及审美判断 |

## 六、易混概念对照（本模块最值钱的一组）

| 常被混淆 | 区别 |
|---|---|
| **艺术 vs 好看** | 前者是一套制度授予的身份，后者是审美判断。两者可以不重合 |
| **作品 vs 物** | 同一个物，在不同装置里身份不同 |
| **博物馆 vs 仓库** | 前者在做"呈现"，后者在做"保存"。两者的取舍不同 |
| **藏品 vs 展品** | 拥有的 vs 被呈现的，两个集合不重合 |
| **原作 vs 唯一** | 版画是多份原作。**"唯一"是某些门类的性质，不是艺术的定义** |
| **复制 vs 伪造** | 复制品不冒充原件；伪造品冒充 |
| **一级市场 vs 二级市场** | 首次出售 vs 再交易，逻辑不同 |
| **价格 vs 价值** | 前者是共识的当下读数，后者没有公认的度量 |
| **现代主义 vs 当代艺术** | 前者关注"这种媒介能做什么"，后者关注"什么算艺术" |
| **媒介特性 vs 技术限制** | 前者是它成立的理由，后者是它做不到的事 |
| **去语境化 vs 破坏** | 移出原场景会丢信息，也会获得新信息。**两者同时发生** |
| **公共艺术 vs 户外雕塑** | 前者要考虑"非自愿的观众"这一层 |

## 七、本模块「不确定就别写」清单

**以下一律不写：**

- ❌ 任何对具体作品、艺术家、流派的价值排序与高低判断
- ❌ 「这是杰作」「大师之作」这类评定
- ❌ 「怎么看懂艺术」这类指导
- ❌ 任何价格、成交额、市场指数、艺术家排名
- ❌ 精确年份（只用世纪与"近代/现代/当代"这类粒度）
- ❌ 艺术趋势预测
- ❌ 对任何国家文化政策、艺术体制的优劣评价
- ❌ 具体展览与美术馆的推荐
- ❌ 艺术家的生平八卦

> ⚠️ **本模块最容易滑向的地方**：写着写着变成了鉴赏课。
> **一旦出现"这幅画的妙处在于……""看懂了这一点你就懂了"，这张卡就已经不在讲系统了。**
> 而且它会和 `自我探索` 6.2 撞车。

## 八、写作提醒

1. **每讲一个东西，先问它进了哪套装置。** 是谁把它放进去的、放进了哪里、由谁解释。
2. **分期只讲结构，不讲细节。** 讲"这个阶段在解决什么问题"，不讲"这个阶段有哪些名家名作"。
3. **不做高低。** 讲一个流派在回应什么，不讲它比另一个流派强。
4. **与 `自我探索` 6.2 分工要反复确认。** 那边讲判断，这边讲系统。**碰到"好不好"的问题，指过去，不自己答。**
5. **用世纪，不用年份。**

## 九、资料来源分级（本模块）

| 级别 | 对应 |
|---|---|
| A | 艺术史与艺术社会学的学术著作、博物馆与专业机构的公开材料 |
| B | 通行艺术史教材、有编辑把关的艺术媒体 |
| C | 优质艺术写作、纪录片 |
| D | 艺术博主、拍卖行软文、"一分钟看懂名画"类内容 | → **本模块危害最大，一律不作依据** |

> 这个模块的 D 级内容有一个特征：**它把"欣赏"包装成了"知识"。**
> 判断的办法不是看它讲得动不动人，是问：**它在讲这个系统怎么运转，还是在替你做判断？**
