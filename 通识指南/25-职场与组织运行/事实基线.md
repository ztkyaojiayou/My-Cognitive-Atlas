# 职场与组织运行 · 事实基线

> **卡片写作时只引用本文件，不自行生成硬事实。**
> 见 `../事实基线规范.md`。

---

## 一、本模块的头号禁令：**不写职场生存法则**

- ❌「这样汇报，领导才会满意」
- ❌「做到这三点，你就不会被边缘化」
- ❌「向上管理的核心是……」
- ✅「汇报的形式会改变信息的形状——口头传递保留细节但不可回溯，书面留下记录但压缩了背景」

**判据：把"你该怎么做"换成"这样做的代价是什么"，如果换完就不成立了，那就是生存法则，不是机制。**

> 这条禁令和 `24-沟通与人际协作` 是同一条：**方法可以写，承诺不行。**
> 区别在于这个模块连"方法"都少写——因为组织层面的应对高度依赖具体处境，
> 一套在 A 公司有效的策略，在 B 公司可能正好相反。**所以这里主要写结构，不写打法。**

---

## 二、本模块的第二号禁令：**不评价真实的组织**

- ❌ 任何真实公司、机构、行业的好坏评价与排名
- ❌ 任何薪资、裁员比例、晋升率、离职率数字
- ❌ 任何职级体系的优劣比较
- ❌ 「某类企业就是……」「某行业都……」式整体断言
- ❌ 对具体的组织事件、人事安排的评论

需要举例时，**用"一个组织""某类结构"这样的抽象描述**，不落到具体对象。

---

## 三、本模块的第三号禁令：**不对人作类型断言**

- ❌「什么样的人适合做管理」「内向的人不适合……」「某某性格的人会……」
- ❌ 任何 MBTI、九型之类的人格分类与岗位匹配的说法
- ✅「这个位置要求的是……，它会筛选出倾向于……的行为」（说的是位置，不是人）

## 四、可写的框架与机制（白名单）

> 凡是**有名字的框架**，都要写齐：结构、来历、失效条件、代价。
> 机制性概念不强制四件套，但**每个机制都必须写清它换来了什么、代价落在哪**。

### 4.1 结构与权力

| 概念 | 可写内容 |
|---|---|
| **层级** | 它换来的是**协调**：人多了必须有人汇总、排序、拍板。代价是**信息损失**——每过一层，信息被压缩一次、被调整一次。**层级不是官僚的产物，是规模的产物** |
| **管理跨度** | 一个人直接管多少人。跨度大则信息传得快、下属自主性强，代价是指导不足、质量波动；跨度小则控制严、标准统一，代价是层级变多、决策变慢。**这是一个取舍，没有最优值** |
| **权责一致** | 责任与权力应当对等。**责任大于权力**，人就只能背结果却没有手段，行为会退化成推诿与走流程；**权力大于责任**，则决策不必承担后果，容易轻率。**两者都失衡，后者更常见也更隐蔽** |
| **错位的自动填补** | 有责任没权力的人，会去找一个能补上这块权力的人（上级、外部、关系），于是形成**非正式依赖**——这解释了为什么有些事必须靠「某人点头」才推得动 |
| **边界不清的后果** | 授权边界没写清时，人倾向于**把所有事都上报**（因为越权比漏报更危险）。于是层级变慢，而慢又常被解释为「这个人能力不行」——一个把结构问题读成人格问题的典型 |
| **正式权力** | 来自职位：能分配任务、批预算、决定人事、签署文件。它写在组织架构图上，可被指认 |
| **非正式权力** | 来自三处：**信息位置**（比别人早知道、知道得全）、**否决点**（他不同意这件事就推不动）、**专业权威**（涉及某类问题别人只认他）。**这三样都不出现在架构图上** |
| **资源依赖理论** | 由普费弗与萨兰西克（Pfeffer & Salancik）系统化。**A 对 B 的权力，来自 B 对 A 的依赖程度**——依赖越强、越无可替代，对方对你的权力越大。**所以"重要"不等于"有权"，"缺了不行"才是** |
| **它的失效条件** | 依赖关系在紧急状态下会翻转——平时不重要的位置，在特定危机里可能变成唯一选项。**平时画出的权力图，在突发情况下未必成立** |
| **它的代价** | 用依赖视角看组织，容易把所有关系都理解成博弈。**很多协作确实不靠权衡，靠的是共同目标和习惯**——把它全部还原成依赖，会漏掉这一大块 |

### 4.2 激励与考核

| 概念 | 可写内容 |
|---|---|
| **古德哈特定律** | 由查尔斯·古德哈特（Charles Goodhart）提出，原是对货币政策指标的观察，后被广泛引申：**当一个指标成为目标，它就不再是一个好的指标**。原因不是人坏，是**指标本来只是对目标的粗略代理，一旦成了考核依据，优化指标本身就比优化目标省力** |
| **它的失效条件** | 指标与目标高度重合、且难以被单独优化时（例如某些可直接观测的产出），这条定律的影响就小。**它不是"一切考核都无效"** |
| **考核的三种扭曲** | ① **优化指标本身**：把可测量的部分做漂亮，不管它是否真的有用；② **忽略未被测量的部分**：没被写进考核的工作，会系统性被挤掉；③ **博弈**：在规则边界上找空间，或把成本转移到其他部门 |
| **委托—代理** | 委托人与代理人利益不一致且有信息差。**考核的本质是给这层不对称加成本**，而任何考核都会被代理人反过来适应——这是结构性的，不是道德问题 |
| **锦标赛理论** | 由拉齐尔与罗森（Lazear & Rosen）提出。把晋升设计成一场内部竞赛：**奖金差距越大，参赛者越努力**。代价是**合作下降**——同僚同时是竞争对手时，帮助对方等于削弱自己 |
| **它的失效条件** | 需要"努力能改变结果"这个前提。当晋升主要由资历、关系或名额决定时，锦标赛的激励效果会迅速失效，剩下的只有竞争副作用 |
| **彼得原理** | 劳伦斯·彼得（Laurence Peter）提出的一种**讽刺性观察**：在层级组织中，人会一直升到他不胜任的那个位置为止。**必须写成"一种广为流传的观察"**——它没有被系统检验为定律，也解释不了为什么很多人在原岗位表现良好 |

### 4.3 信息

| 概念 | 可写内容 |
|---|---|
| **信息在层级里的衰减** | 每经过一层，信息被压缩（去掉它认为不重要的）、被调整（去掉对自己不利的）、也被延迟。**这不是说谎，是每一层都在做"该报什么"的判断** |
| **报喜不报忧的结构性原因** | 传递坏消息的人，往往同时承担"发现了问题"和"制造了问题"两种解读的风险。**当传递坏消息有代价时，坏消息会变少**——减少的不是问题，是消息 |
| **它的代价** | 想解决上报失真，常见做法是加大追责，而**加大追责会让失真更严重**——因为它提高了说真话的成本。这是一个会自我强化的循环 |
| **康威定律** | 梅尔文·康威（Melvin Conway）提出：系统的设计会反映设计它的组织的沟通结构。**它解释了很多"技术问题"其实是组织问题** |
| **它的失效条件** | 当设计由少数人集中完成、或者直接采用外部既定标准时，设计与组织沟通结构的对应关系会明显减弱——**它描述的是「多人协商出来的系统」，不是所有系统** |
| **它的代价** | 用它解释一切，容易把纯技术约束（性能、成本、兼容）也还原成组织关系。**它提供的是一个视角，不是一个万能解释** |

### 4.4 协作与变革

| 概念 | 可写内容 |
|---|---|
| **协作成本的非线性** | 人数增加时，需要维护的关系数**不是按人数增长，是按组合增长**——人越多，路径增长得越快。这是流程、会议、分工出现的根本原因：**它们是把关系数压回可控范围的手段** |
| **它的代价** | 流程一旦建立就倾向于自我存续。**去掉一条流程比建立它难得多**，因为没人负责"证明它不需要" |
| **组织文化** | 不是墙上那句话，是**在这里，什么行为会被奖励、什么会被惩罚、什么会被默许**。它由实际决策累积而成，与宣称的价值观可以完全无关 |
| **怎么看出真实文化** | 看最近处理的几件事：谁被提拔、谁被放过、什么被追究、什么被称作"特殊情况"。**"特殊情况"出现的频率，往往就是规则的实际强度** |
| **变革为什么难** | 四件事叠加：**路径依赖**（现有结构是围绕过去的问题长出来的）、**沉没成本**（已经投进去的东西让人不愿放弃）、**既得利益**（现行安排里有人的位置更好）、**协调失败**（每个人都知道该改，但没人愿意先动） |
| **为什么反对声总是更响** | 受损的人明确、受益的人分散。**受益摊到每个人头上都不多，受损的却是一个个具体的对象**——少数集中、多数分散时，组织里听到的几乎总是反对 |
| **增量结构与存量结构** | 格子（名额、职级）随规模增长而增加的是增量结构，总数固定的是存量结构。**同样的行为在两种结构里意义完全不同**：前者把事情做成就会有位置，后者位置得从别人手里挤出来 |
| **它的失效条件** | 危机状态下，上述四条会同时松动——**危机是变革最常见的触发条件，也是唯一不依赖共识的触发条件**。这不是说危机是好事，是说明为什么很多组织平时改不动 |

### 4.5 公平感

| 概念 | 可写内容 |
|---|---|
| **结果公平与程序公平** | 前者是分到的结果是否合理，后者是**分配的过程是否一致、透明、可申诉、无偏见**。两者是独立的 |
| **这一区分的来历** | 它是在对「公平＝结果合理」这一直觉的反思中逐步分开的：研究者发现，同一种结果如果由不同的程序产生，人的接受度差别很大。此后「程序」被单列出来，成为与结果并列的一个维度。**卡片引用时不要挂具体人名，只需说明这个区分是怎么被逼出来的** |
| **一个反复出现的观察** | 在组织情境中，**程序公平对接受度的影响常常大于结果本身**——同样的结果，如果过程被认为是公正的，人的反应会好得多；反之，即使结果不差，也会引发强烈不满 |
| **它的失效条件** | 当结果差距极大时，程序再公正也压不住反应。**程序公平能缓解，不能抵消** |
| **它的代价** | 强调程序会增加成本（要走步骤、要留记录、要解释），而且在紧急情况下拖慢速度 |

## 五、易混概念对照（本模块最值钱的一组）

| 常被混淆 | 区别 |
|---|---|
| **个人问题 vs 位置问题 vs 结构问题** | 换个人就好、换个人也一样、换个组织也一样——三种判断，应对方式完全不同 |
| **正式权力 vs 实际影响力** | 前者写在架构图上，后者来自信息、否决点和专业权威，常常不重合 |
| **重要 vs 有权** | 重要是"这件事要紧"，有权是"缺了你不行"。资源依赖看的是后者 |
| **考核 vs 目标** | 考核是目标的代理指标。一旦成为目标，代理关系就断了 |
| **晋升 vs 成长** | 前者是位置的变化，后者是能力的变化。两者相关，但不是一回事 |
| **文化 vs 口号** | 前者由实际奖惩累积成，后者是宣称的。判断看前者 |
| **流程 vs 官僚** | 流程是协作成本的产物，有它的功能；官僚是流程脱离目的后的状态。**两者不能混着骂** |
| **稳定 vs 不变** | 稳定是动态维持的结果，不变是没人推动。看着像一回事，成因相反 |
| **沉没成本 vs 既得利益** | 前者是"已经投入所以不舍得"，后者是"现行安排对某些人有利"。后者更常是变革的真正阻力 |
| **不满 vs 不公平感** | 前者是结果不合意，后者是过程被认为有偏。**后者更难安抚，也更伤组织** |

## 六、本模块「不确定就别写」清单

**以下一律不写：**

- ❌ 职场生存法则、向上管理话术、"如何被看见"
- ❌ 任何真实公司、机构、行业、职级体系的评价与排名
- ❌ 薪资、裁员比例、晋升率、离职率等任何数字
- ❌ "什么样的人适合做管理"式的人－岗位匹配断言
- ❌ 把彼得原理当成已被证实的定律
- ❌ 任何管理学畅销书的具体方法论（除非有名字、有提出者、有可查结构，且写清失效条件）
- ❌ 对正在发生的具体组织事件、人事变动的评论
- ❌ 任何"照做就能"的承诺

> ⚠️ **本模块最容易滑向的地方**：把结构描述悄悄换成立场表达。
> 「层级会损失信息」是机制；「层级就是用来压人的」是立场。**后半句不写。**

## 七、写作提醒

1. **每个机制都要写代价。** 层级、考核、流程、程序公平，全都既有功能也有代价。只写一边就是推荐。
2. **区分三层归因**：这个人的问题 / 这个位置的问题 / 这类结构的问题。**这是全模块最有用的一个判断，每张卡都可以回到它。**
3. **不做道德判断。** 报喜不报忧、优化指标、博弈规则，都是人在特定激励下的正常反应。写清激励，不写"这种人怎样"。
4. **例子用抽象描述。** 写"一个把考核挂在个人头上的团队"，不写具体行业或公司。
5. **不写"你应该"。** 用"处在这个位置上的人，通常会……它的代价是……"。

## 八、资料来源分级（本模块）

| 级别 | 对应 |
|---|---|
| A | 组织行为学与经济学的同行评审研究、提出者的原著 |
| B | 通行教材对该框架的转述、专业机构的公开报告 |
| C | 优质商业报道、管理类通俗读物 |
| D | 职场博主、成功学课程、"我在大厂学到的事"类内容 | → **本模块危害最大，一律不作依据** |

> 这个模块的 D 级内容有一个特征：**它把一个具体处境下的有效做法，说成了普遍规律。**
> 判断的办法不是看它讲得对不对，是问：**换成另一个结构，这个做法还成立吗？**
