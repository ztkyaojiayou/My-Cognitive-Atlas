    一、这个领域在解决什么问题¶

    关于技术和 AI，项目里已经有两块内容：

    已有内容 讲了什么
    自我探索 4.4 科技与未来（十问） 技术在改变文明还是改变人的本质 / AI 会带来什么根本性变化 / 人类会被机器超越吗 / 技术被谁以什么逻辑推动 / 解放还是新的束缚 / 未来的社会如何组织 / 如何面对不确定性 / 什么是"好的未来" / 我们为怎样的文明负责 / 个体该如何自处
    读万卷书 科技与未来 11 本 系统之美、未来简史、从 0 到 1、科技想要什么、奇点临近、生命 3.0、AI 2041、创新者的窘境、浪潮之巅、芯片战争、复杂

    这十问把"未来学"那一层占满了。 所以这个模块不碰它们。

    它处理的是另一层，也是缺的那一层：

    这些东西具体是怎么运作的。

    • 你发出的一个请求，中间经过了哪些环节
    • 你的数据是从哪几个口子出去的
    • 推荐算法在优化什么，以及"优化什么"为什么决定了你看到什么
    • 大模型在算什么，它为什么会编
    • 为什么"去掉名字"不等于匿名
    • 平台为什么长成那个样子
    • 内容是怎么被审的、账号是怎么被验证的
    • 一张截图能证明什么、不能证明什么

    一句话概括：

    这个模块不预测未来，也不评价任何产品。它讲的是你每天在用、但通常不知道它怎么运转的那套东西。

    四、外行最容易误解的五件事¶

    误解一：以为互联网有一个中心。

    它没有。它的设计目标之一就是在局部坏掉的时候整体还能转。

    你发出的一条消息会被切成小包，各自找路走，到了再拼起来。同一批包可能走了不同的路线，也可能顺序到达。"中心"没有，但"集中点"有——少数几个交换中心、少数几家云服务商、少数几条海底光缆。这两件事经常被混为一谈。

    误解二：以为"去掉名字"就叫匿名。

    不是。一堆看起来无关的字段凑在一起，往往就足以把人认出来。

    出生日期、邮编、性别——这三样组合，在足够大的人口里就能把多数人区分开。加上位置轨迹、购物记录、设备型号，识别率还会上一个台阶。这件事在数据研究里有个名字，叫重新识别。

    所以"去标识化"和"匿名"是两个强度差得很远的状态，中间隔着很多层。

    误解三：以为推荐算法在找"你会喜欢的东西"。

    它在优化一个具体的数——点击率、停留时长、互动次数，或者别的什么。

    优化哪个数，结果就不一样。 优化点击率会推耸动的；优化停留时长会推让人停不下来的；优化"看完"会推短的。同一个用户、同一批内容，换一个目标函数，出来的是另一个信息流。

    所以问"算法在想什么"，第一个该问的是：它在最大化什么。

    误解四：以为大模型在查资料。

    它在生成。

    它的基本训练任务是预测下一个词元，反复做几万亿次之后，它学会了什么样的词接在什么样的词后面。所以它是"接着往下写"，不是"去档案里找"。这决定了它给出来的东西可能非常通顺，而内容没有依据。

    理解这一点，后面关于"它为什么会编"的所有问题才有解释。

    误解五：以为有截图就有真相。

    截图能改，改起来不需要任何技术。图片能合成，合成得越来越像。视频也能。

    这倒不是说"什么都别信"，是说证据链多了一环要查：这张图最早出现在哪里、原始出处是什么、有没有元数据、有没有被裁过。以前"有图有真相"是不言自明的，现在它需要被证明。

    这个模块的五条硬边界¶

    1. 不预测。 不写「未来 AI 会……」「几年之内会……」。裸眼可见的趋势也不写。
    2. 不评价任何产品、公司、平台、政策。 不点名，不排名，不比较。
    3. 不给"该怎么用"的建议。 不写「你应该关掉 XX」「建议少刷手机」。
    4. 不写具体参数、价格、性能数字。 不写模型参数量的具体值、不写渗透率与用户数。
    5. 不写成说明书。 讲结构，不讲操作步骤。

    所以这个模块不教你保护隐私，也不替你判断该不该担心。它给的是——当有人说"算法推荐""大模型""数据泄露"时，你知道那说的是哪一层、由什么构成、它做得到什么、做不到什么。
