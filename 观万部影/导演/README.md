# 导演画像 · 索引

> 125 部电影背后，是一批反复追问同一个问题的人。
>
> 导演轴要看的不是"他拍了哪些片"，而是：**他一辈子到底在问什么？**

---

## 选人标准

本清单按 **125 部中出现部数 ≥ 2 取全部**（2026-11-09 定稿，共 16 位）：

- 每人至少有 2 部作品进入 125 部清单，画像里的判断都能在现有篇目中找到证据。
- 出现 2 部的正好 10 位，全部收入，不再按影史地位二次取舍。
- 本索引**不按国籍配平**，只看片单密度；想看"每个国家该记住谁"，去 [影史导演总表](影史导演总表.md)（138 位，按时代分组、时代内按国别分组）。
- 代价是漏掉一些"只有 1 部但极重要"的作者（小津安二郎、斯科塞斯、费里尼、陈凯歌等）——这是片单密度口径的必然结果，不是遗漏；完整影史坐标看总表。

## 怎么读

每位导演固定六块：

1. **一句话作者签名**（开头引用）
2. **他是谁**（生平与位置，只写确凿的）
3. **时代位置**（属于哪个运动/工业阶段）
4. **反复出现的主题**（3–4 个，每个配本清单内的具体片目）
5. **手法签名**（镜头/剪辑/声音/色彩，只写确凿的）
6. **一句话记住**

> 读法：先看"他反复在问什么"，再看他"怎么拍"。**主题决定他拍什么，手法决定他为什么只能这样拍。**
