# 文学与经典 · 事实基线

> **卡片写作时只引用本文件，不自行生成硬事实。**
> 见 `../事实基线规范.md`。

---

## 一、本模块的头号禁令：**不谈高下**

- ❌ 评价任何作品、作家、流派、文学传统的高低
- ❌ 「这是杰作」「这位是大师」「这本书比那本好」
- ❌ 「必读」「值得一读」「不可不读」这类推荐语
- ❌ **评价任何国家的出版制度、审查制度、文学体制的优劣**
- ✅ 「一本书从写出来到被读到，中间要过选题、编辑、书号、印行、发行几道」

**这一条是本模块的分工，不是回避。**
「什么是经典」「文学有没有高下之分」「为什么要读小说」「悲剧为什么让人爱看」——**这些在 `自我探索` 6.1 文学里已经讲过，那里讲得比这里细。**

本模块只讲**它由什么构成、经过哪些手、谁在决定它重要**。

---

## 二、本模块的第二号禁令：**不点名**

**这个模块比其他模块更严：一个作家、一本书、一家出版社、一本期刊、一个奖项的名字都不许出现。**

- ❌「某作家的小说……」→ ✅「19 世纪报纸上的连载小说……」
- ❌「某奖改变了这本书的命运」→ ✅「一个奖会改变它的可见度」
- ❌ 具体书名、笔名、社名、刊名、奖名、丛书名

> 理由有两条：
> ① **具体作品归 `读万卷书`**（那里有 27 本文学深解），点名就是重复。
> ② 只要允许点名，就会出现"点名即背书"——**而本模块不谈高下。**

**术语可以写**（文类、类型文学、连载、单行本、转译、经典化、评点、版税、码洋……），**理论家的名字也不点**——概念说得清，不需要挂人。

---

## 三、本模块的第三号禁令：**不写任何数字**

- ❌ 印数、销量、版税、稿酬、码洋、实洋的具体数额
- ❌ 榜单名次
- ❌ **精确年份**（用"世纪""年代""近代/现代/当代"）
- ❌ 字数、册数、库存周转天数

> **机制讲得清，数字是装饰。** 写"寄销"要说的是"印出去的数不等于卖掉的数"，不是"退了多少万册"。

---

## 四、本模块的第四号禁令：**不教写作、不教鉴赏**

- ❌「怎么写出好小说」「怎样设置人物弧光」
- ❌「读经典要读出什么」
- ❌ 修辞与文体技巧教学

> 讲"连载会改变写法"，可以；讲"所以你该这样写"，不行。

## 五、可写的概念与机制（白名单）

### 5.1 文类

| 概念 | 可写内容 |
|---|---|
| **"文学"这个范畴本身是近代的** | **文类观念远早于近代**——诗与散文的对立、诗学传统、"诗""史""论"的分家，都在大学文学系出现之前就存在。近代发生的是另一件事：**文学系把这些既有的文类收进来，当成了课表**。它没造出新格子，但把旧格子变成了人人都要过的关卡 |
| 小说 | 近代才成为被摆得最高的文类。**位置换了一轮**——从"诗被摆在最上"到"小说被摆在最上"，前后不过一两百年。⚠️ **只写位置，不写"最重要""最高级"** |
| **散文的边界最模糊** | 中文的"散文"大致落在英文的 **essay 与非虚构之间**。注意 **prose 是另一个层级**——它指一切非韵文（小说、论文都算），是上位范畴。把三者并列会推出"散文包含小说"这种明显的错。**对不齐的正是这个层级差** |
| 诗 | 诗与歌同源，分行、格律、吟唱与朗读的分家是后来的事。**"诗"这个字在中文里长期同时指诗、词、曲**，边界比英文的 poetry 宽 |
| 戏剧 | **它有两套读者**：读剧本的人和看演出的人。同一个文本，在两种使用方式里是不同的东西 |

### 5.2 类型文学

| 概念 | 可写内容 |
|---|---|
| **"类型"是一个出版标签** | 科幻、推理、言情、武侠成为"类型"，靠的是一整套配套：专门的出版社或书系、奖项、杂志、读者社群、书店的货架。**这些装置没齐之前，只有作品，没有"类型"** |
| **纯文学 vs 类型文学** | 这个二分**主要是销售与评论的划分**，不是美学上的严格分级。它的用处在于让书店知道摆哪里、让评奖知道归哪一组 |
| **中文世界的特殊形态** | 还有一条独立的线：**网络文学**。它主要不在书店里，而在平台上；主要不靠印数结算，靠付费阅读与订阅。**它是另一套装置长出来的另一类文类**。⚠️ **但不许写成"两套体系互不承认"**——交叉一直在发生（入会、出版、评奖都有），只能说**两边各有一套通行的凭证，一本在另一套里通常不通用** |

> ⚠️ **这里不许滑向"类型文学算不算文学"或"雅俗有没有界限"。** 那是判断层。

### 5.3 出版

| 概念 | 可写内容 |
|---|---|
| **一本书的基本流程** | 选题 → 组稿或投稿 → 审读 → 编辑加工 → **三审三校** → 装帧设计 → 申请书号 → 印制 → 发行 → 上架 |
| **三审三校** | 中文出版的实际工序：三次审读、三次校对。**它是"一本书被几个人分别看过"这件事的固定化** |
| **书号** | 由新闻出版管理部门分配。**没有它，这本书进不了正规发行渠道**——所以它是一道准入 |
| **寄销与退货** | 书店先铺货、后结算，卖不掉可以退。**所以"印数"从来不等于"销量"**——印出去的一大部分可能原路返回 |
| **码洋与实洋** | **码洋**是定价乘印数（账面）；**实洋**是实际回款（扣掉折扣与退货）。**两个数差得很远，这是行业里最容易被外人弄混的一对词** |
| 它的代价 | 这一整套流程让书能被稳定地做出来、送出去，**代价是每一道都有否决权**——选题可以被否、稿子可以被退、书号可以被卡、书店可以不进货。**任何一道断了，文本就到不了读者手里** |

### 5.4 作者作为一种职业

| 概念 | 可写内容 |
|---|---|
| **版税制** | 按"定价 × 销量"的比例付酬。**作者的收入直接绑在销量上** |
| **稿酬制** | 一次性买断或按字数付。**作者的收入与销量无关**——这两种制度的激励方向完全不同 |
| **预付** | 先付一笔，之后从应得版税里扣。**它其实是出版方对这本书的一个风险判断**，不是稿费 |
| **它的代价** | 让写作可以成为一种职业，**代价是写作的时间结构被市场节奏改写**——交稿期、销量、下一本能不能出，都成了写作的外部条件 |
| **中文语境的一层** | 全职写作者相对少，**多数写作者另有主业**。这不说明写作不重要，说明**靠写作单独谋生这件事，门槛在收入结构上，不在才华上** |
| **写作班** | 一套成建制的东西：课程、导师、同侪、结业作品。**它把"拜师"变成了"入学"**，也让写作有了可复制的训练路径。中文语境里这套建制相对薄，多以工作坊、改稿会的形式存在 |

### 5.5 翻译

| 概念 | 可写内容 |
|---|---|
| **不可译的那一部分** | 双关、方言、韵律、称谓系统、文化专名。**这些东西换一种语言就会掉**，而它们往往正是最没法用另一种语言替回去的 |
| **译者做的不是搬运** | 他在两种语言的约束之间做一连串取舍：这里保意思还是保节奏，那里保陌生感还是保顺畅。**每一个取舍都在重写** |
| **归化与异化** | 两条路：把译文改得像本地话（读着顺，但原味淡）；或者保留原文的隔阂感（读着涩，但保留了"这是别处来的"）。**两条都有代价，没有正解** |
| **转译** | 从一个译本再翻成第三种语言。**很多小语种文学是先经大语种转译才进入中文的**——这意味着中文读者读到的是"二手"的，而且那个中间语言的取舍也叠了进来 |
| **译本会老化** | 语言在变。几十年前的译本今天读着会旧，所以要重译。**这意味着"同一本书"在不同年代是不同的文本** |
| 它的代价 | 翻译让文学能跨语言流通，**代价是每一次流通都带上了译者的判断**——而那个取舍的过程，书上不会再写一遍。⚠️ **不许写成"译者不署名"**：译者署名是出版规范，封面或版权页必列 |
| **两份彼此独立的权利** | 一本书的中文**出版授权**通常有期限，到期后别家可以重新谈。但**旧译本的译文权利在译者手上，不跟着到期**。谈得拢就沿用旧译，谈不拢才另请人重译——**新译本多半是这么出现的，不是因为旧译本过时** |

### 5.6 中文世界的现代文学建制

| 概念 | 可写内容 |
|---|---|
| **"文学"成为一门学科** | 大学里设文学系、开文学史课、编文学选本——**这套建制把"哪些作品值得读"变成了课程表** |
| **文学期刊** | 近代出现的定期刊物，是作品进入公共视野的主要通道之一。**它同时是发表渠道、评价渠道和圈子** |
| **社团与流派** | 一群人共同宣称一种写法，是近代文学史的基本单位。**流派常常是事后被命名的，当事人未必这么看自己** |
| **白话取代文言** | 书面语言的一次整体更换。**它改变的不只是用词，还有"谁有资格写"**——文言是一套需要长期训练的书写系统，白话把这套门槛拆掉了 |
| 它的代价 | 建制让文学有了培养、评价、保存的通道，**代价是它也规定了什么算"文学"**——不合这套建制的写作，常常连被讨论的入口都没有 |

### 5.7 经典化

| 概念 | 可写内容 |
|---|---|
| **经典不是自然长成的** | 时间本身不筛东西，筛东西的是一连串具体动作：**重印、选入教材、持续被评论、被重译、被改编** |
| 几条通道 | 教材与推荐书目、文库与丛书、翻译、评论累积、影视改编、奖项。**每一条都可能断，断了它就慢慢淡出** |
| **教材是最强的一条** | 一本书进了课本，就意味着**一代人被迫读过它**。这个规模效应，任何书评都做不到 |
| **也会出去** | 有些书不再版、不再教、不再被讨论，就退出了。**经典名录是会变的，只是变得慢** |
| 它的代价 | 经典化让一部分作品获得长期生命，**代价是它同时造成遮蔽**——名录有限，挤进去的和挤不进去的，被注意的机会差得很远 |

> ⚠️ **这里不许回答"什么才算经典"。** 那是 `自我探索` 6.1 问题五。
> 本卡只讲：**"经典"这个身份是通过哪些动作被反复确认出来的。**

### 5.8 文学批评

| 概念 | 可写内容 |
|---|---|
| 三种批评 | **媒体书评**（给读者一个入口）、**学术批评**（在学科内部对话）、**导读与评点**（贴着文本说） |
| **它们服务的人不一样** | 书评服务读者，学术批评服务同行，导读服务第一次读的人。**同一个文本，在三种写法里被处理成三样东西** |
| **中文传统的评点** | 一种独特的形态：**批语写在正文旁边**，与文本同页共存。读者读到哪，批语就在哪。⚠️ **它的特殊性在空间，不在时间**——评点者在时间上恰恰是读完才批的。**它把评论钉在正文旁边，让"读正文"和"读评语"变成同一个动作**，而不是"边读边评" |
| **批评也有位置** | 谁在写、发在哪、给谁看，决定了这段批评有多大分量。**同一个人说的话，换个地方发，效果不一样** |
| 它的代价 | 批评给作品一个位置、给读者一个入口，**代价是它也参与了"什么值得读"的分配** |

### 5.9 奖项与榜单

| 概念 | 可写内容 |
|---|---|
| **三种排序，依据不同** | **销售榜**按销量；**媒体或机构榜单**按一批人的意见；**推荐算法**按行为数据。**三者反映的不是同一件事** |
| 奖项的机制 | 通常由评审团或会员投票产生。**评审团制偏向少数人高度认可，投票制偏向多数人不反感** |
| **入围名单本身就有用** | 营销上可以写"入围某某奖"。**它不需要获奖就已经产生作用** |
| 奖项的作用 | 给一本书**一个可引用的标签**，标签改变它的可见度与发行命运 |
| 它的代价 | 奖项把复杂判断压缩成一个名单，**代价是没进名单的更难被看见**；而且评奖的类别划分，本身就在规定"什么算一类" |

### 5.10 连载与单行本

| 概念 | 可写内容 |
|---|---|
| **报纸连载** | 近代出现的一种主要形态：故事按期登在报纸或杂志上，读完一期等下一期。**它要求每一期都留一个让人愿意再买一次的理由** |
| **中文的章回体** | 与说书传统相关：每回有回目、回末留扣。**它是口头表演的节奏被写下来的痕迹** |
| **网络连载** | 按章更新、读者实时反馈、按字数或订阅计酬。**计量方式直接进入了写作**——章的长度、悬念的位置、总体的篇幅，都被这套计量改写 |
| **单行本** | 一次给出全部。**力量可以攒到最后一次放**，节奏可以缓，结构可以更复杂 |
| **它改变的到底是什么** | **不是装内容的盒子，是一条约束。** 同一个故事，在"每期要留人"和"一次给完"这两种约束下，会长成两个样子 |
| 它的代价 | 连载让故事能被持续供养、让作者有稳定收入，**代价是它把节奏的决定权分了一部分给发表周期** |

## 六、易混概念对照（本模块最值钱的一组）

| 常被混淆 | 区别 |
|---|---|
| **经典 vs 畅销** | 经典靠长期确认，畅销靠当下销量。两者可以重合，也可以完全不相干 |
| **经典 vs 古老** | 不是活得久就算，是中间一直有人在重印、在教、在讨论 |
| **类型 vs 文类** | 文类是学院分类，类型是出版标签 |
| **印数 vs 销量** | 寄销制下，印出去的一大部分可能退回来 |
| **码洋 vs 实洋** | 账面（定价×印数）vs 实际回款（扣折扣与退货） |
| **版税 vs 稿酬** | 收入绑销量 vs 收入与销量无关 |
| **预付 vs 稿费** | 预付是风险判断，之后要扣回 |
| **翻译 vs 转述** | 翻译贴着原文的句子走，转述只保意思 |
| **转译 vs 直译** | 前者经过第三种语言，后者不经过 |
| **译本 vs 原著** | 两个文本，不是同一份拷贝 |
| **版次 vs 印次** | 版次管内容（实质改动才升版），印次管印刷次数。**第 1 版第 3 次印刷 = 重印两次，内容没改** |
| **内容本 vs 实物本** | 前者是文字本身（版次管），后者是印出来的一本（印次管）。**译本换掉的是语言，内容本没动，但它已经不是同一份东西** |
| **名录 vs 名单** | 名录要几十年反复确认（重印、教材、丛书）；名单是一年一次的奖项入围。**两个词长得像，机制完全不同** |
| **批评 vs 读后感** | 批评要落在可讨论的依据上，读后感只落在感受上 |
| **销售榜 vs 推荐算法** | 一个按买，一个按看与点 |
| **连载 vs 单行本** | 两条不同的写作约束，不是两种包装 |
| **文学期刊 vs 出版社** | 定期发表 vs 成书出版，两套通道各有各的筛选 |
| **网络文学 vs 类型文学** | 两套装置长出来的两类东西，不能简单归为一类 |

## 七、本模块「不确定就别写」清单

**以下一律不写：**

- ❌ 任何作品、作家、流派、传统的高下评价
- ❌ 任何国家的出版 / 审查 / 文学体制的优劣评价
- ❌ **任何作家、作品、出版社、期刊、奖项、丛书的名字**
- ❌ 印数、销量、版税、码洋的具体数额，榜单名次
- ❌ 精确年份（含"某某年某某运动"）
- ❌ 任何推荐书目
- ❌ 写作技巧与鉴赏指导
- ❌ 具体作品的剧情与人物分析（那是 `读万卷书` 的活）
- ❌ 作家的生平轶事与八卦

> ⚠️ **本模块最容易滑向的地方是"书评腔"。**
> **一旦出现"这本书的妙处在于""读懂了这一点你就读懂了"，这张卡就已经不在讲系统了。**
> 而且它会和 `自我探索` 6.1、`读万卷书` 同时撞车。

## 八、写作提醒

1. **每讲一个东西，先问它进了哪套装置。** 谁选的、谁定的、谁付代价。
2. **生产与评价要分清。** 出版是生产，奖项是评价；翻译是流通，教材是筛选。**四件事经常被混着说。**
3. **不做高低。** 讲一种形态在回应什么问题，不讲它比另一种好。
4. **与 `自我探索` 6.1 的分工要反复确认。** 那边讲判断，这边讲系统。**碰到"好不好"的问题，指过去，不自己答。**
5. **与 `读万卷书` 的分工要反复确认。** 具体作品全在那边，**这边一个书名都不点**。
6. **用世纪，不用年份。用机制，不用数字。**

## 九、资料来源分级（本模块）

| 级别 | 对应 |
|---|---|
| A | 出版学 / 文学社会学 / 翻译研究的学术著作，行业机构的公开材料 |
| B | 通行教材、有编辑把关的书籍与文化媒体 |
| C | 优质行业写作、出版人口述 |
| D | 「人生必读的 xx 本书」「三分钟读完名著」类内容 | → **本模块危害最大，一律不作依据** |

> 这个模块的 D 级内容有一个特征：**它把"推荐"包装成了"知识"。**
> 判断的办法不是看它讲得动不动人，是问：**它在讲这套系统怎么运转，还是在替你做判断？**
