    通识指南¶

    补足学校教育没覆盖、进入社会才陆续撞见的那部分知识。

    不追求让人显得博学，而是让人面对陌生领域时，知道从哪里开始理解。

    定位¶

    通识指南 是认知体系的基础设施层，与前三个模块互补：

    模块 回答 形态
    读万卷书 书里讲了什么 200 本，每本深解
    自我探索 我的答案是什么 291 问，每问七段
    观万部影 影像让我看见了什么 200 部，每部七段
    通识指南 这个世界有哪些领域、怎么运转 卡片化，可检索

    前三者给深度，这一份给坐标。

    与「自我探索」的分工要特别说清： 自我探索回答"我该怎么想"，通识指南只回答"它是什么、从哪来、怎么运转"。 同一件事碰到时，先查通识指南建立坐标系，再回自我探索形成判断。

    体例：薄卡片¶

    前三份都是"厚文章、少数量"（每篇 5000 字）。这一份反过来：

    • 每张卡片 800–1500 字，8 段结构，见 卡片模板.md
    • 每个一级模块配一篇 3000 字导读
    • 目标是查得到，不是读得深

    硬性纪律¶

    1. 事实基线先行：每个模块开写前，先写 事实基线.md，把易错的硬事实（年份、定义、数字、条文）列出来。卡片只引用基线，不自行生成。
    2. 卡片 8 段齐全，800–1500 字。
    3. 不编造：年份、数字、法条、机构名、参数——不确定就删掉该句，不换一个"看起来合理"的顶上。
    4. 敏感题材（政治、法律、宗教、历史）：只解释机制，不做政治表态，不对任何群体作整体评价。
    5. 写完必跑 python3 tools/verify_cards.py。

    背景：前一批（观万部影第二批）因为事实基线太粗，错误密度是第一批的 3 倍。这个模块事实密度更高，同样的错误代价更大。详见 事实基线规范.md。

    定位校准：这是通识/常识指南，不是观点集（2026-11 定）¶

    前十五个模块跑下来，出了一个问题：不少卡是"换一个角度看"的框架 （「门类是出版标签」「经典是被系统确认出来的」「历史是一面镜子」这类）， 读完让人点头，但没有让人多知道一件具体的事。

    改成常识打底、领域共识做骨架、不写感悟。判据一句话：

    读完这张卡，我多知道了哪几件具体的事？少于三件，不合格。

    该写 不该写
    常识 叫什么、分几类、怎么做、为什么这么做、适用边界在哪 —
    领域共识 ✅ 应该写，写成「史学界通行的看法是……」，标明这是领域里的判断 —
    个人框架 — ❌ 只有这张卡这么说的、无法核对的漂亮总结
    感悟 — ❌「说到底」「换个角度想」「历史是一面镜子」

    同时把卡片维度从隐含改为显式的七个，各领域取所需，不要求写齐：

    维度 读者得到什么 主要用在
    概念 / 知识 听得懂、分得清 所有领域
    方法论 知道这个结论是怎么得出来的 历史、科学、新闻、统计
    观念 / 理念 建立正确的判断 哲学、社会、艺术、宗教
    原则 能迁移到没见过的情形 法律、伦理、健康、安全
    常见误区 避坑 所有领域
    分歧与未决 ★ 知道哪里别太确定 证据不稳的领域：健康、心理、营养、经济、历史年代学
    制度与机构 ★ 知道谁在管、该找谁 制度重的领域：法律、医疗、教育、新闻、职场

    ★ 是新增的两维，补的是原有五维的共同缺口——原来的五维全是"已经定下来的"，缺"没定下来的"和"谁在执行"。

    14-历史与文明是第一个按新标准建的模块。 它的维度配比：方法论最重（03 定年 / 04 考古 / 07 谁在写）， 概念次之（01 / 02 / 05 / 08 / 10），制度（02 / 10）、观念（06 / 09）、分歧（09）各占一席。 为什么方法论最重：历史的核心素养不是"记住发生了什么"，是"知道这个说法是怎么得出来的"。 一个不知道碳十四有校正曲线的人，听到"某遗址距今多少年"就只能全盘接受或全盘怀疑。

    加粗口径（2026-11-10 修订）¶

    原来的「每卡 2–3 处加粗」太含糊，落地时各模块自己漂了：法律中位数 16 处、新闻 12 处、经济 3 处。 现在改成可数的两条口径，写进 卡片模板.md，并加进校验脚本 --bold：

    类型 定义 上限
    行内强调 句中、前面还有正文的加粗 2–4 处
    结构性标签 整行起头、独占语块的加粗（**误区一：……**、单独成行的金句） ≤12 处

    16 模块是第一个按新口径写的，十张卡实测行内强调 4/2/2/2/2/2/2/2/2/2，全部合格。

    ⚠️ 历史遗留：20-法律与法治、21-新闻与媒介素养两个模块按旧口径写成，行内强调 9–23 处不等， 跑 verify_cards.py --bold 会报出来。暂不回溯修改——那要动 24 张已审过稿的卡， 收益只是排版一致，风险大于回报。列入待办，将来重审这两个模块时一并处理。

    第四段由主控统写（2026-11-10 起）¶

    问题：写作 agent 各自写「四、全球与中国」，写出来必然是同一句免责套式（心理学模块七张卡同款收尾）。 办法：这一段不给写作 agent，主控一次性统写十段。

    第一次实测（18 模块）的结论：有效，但不够。

    • 有效：写作 agent 的第四段偷懒问题彻底消失，十段都有实内容
    • 不够：我在同一轮里写的九段，仍然共享同一个修辞框架——九段里八段都是「中文里某个词偏了，所以大家误解了」。 我换了九个切入角度，却没换掉那个壳。审稿一句话点破："九段以中文起头。"

    真正的解法不是"谁写"，是"写完并排看"。 十段并排放进一个视图，首句并列排出来， 雷同立刻现形——这次是靠审稿 agent 做的那张首句对照表才发现的。

    → 下次统写第四段，先列出十段的首句和收尾句并排看一遍，再动笔。

    第二次实测（19 政治模块）：换首句不够，要换骨架。

    这次确实先做了首句并列表，也刻意给了十段不同的切入角度，但审稿仍判定雷同—— 问题从「句首九段带中文」转移到了「骨架十段同构」： 五段用"中文里的某个词"开路，六段用"给读者一句判据"收尾。 把 01 的"政治这个词"和 08 的"官僚这个词"互换，读起来毫无违和——骨架没换，换皮没用。

    有效的解法是按功能分类，每张卡只领一类，不许混用： - 制度差异型：写"同样的目标，不同的安排"（政体分类、分权、选举） - 词语史型：写"这个词怎么来的、为什么带上这层意思"（只给最贴的两张） - 信息环境型：写"读者看到的是哪一层"（国际关系、战争）

    → 下次统写第四段：先给十段分配功能类型，同一类型不超过 3 段，再动笔。

    第三次实测（23 健康模块）：框架分了，收尾没分。

    这次按功能预先给十段分配了十种框架，确实起了作用——审稿判定八段真不同，只有两处复用 （01↔08 都在讲"传播中什么被丢掉"，05↔10 都在讲"两种节奏对不上"）。

    但冒出一个新的雷同形式：收尾的手势。十段里有五段以「所以你可以问一句 / 值得做的不是 A 是 B」收尾， 其中两段连"这一问常常得不到答案"都撞了。骨架换了，收束动作没换。

    另一个新问题：十段里有四段的收尾从「解释」滑成了「你可以这样做」—— 这是本模块的红线（不给做法建议），而且是在我反复强调这条禁令的情况下发生的。

    → 下次统写第四段，除了分配框架，还要预先规定各段的收尾方式（问句／观察／代价／对照）， 并逐段检查有没有从描述滑成祈使。

    第四次实测（24 沟通模块）：骨架换了，收尾的手势还会回归。

    这轮预先给十段分配了十种骨架，审稿确认话题骨架确实换了，十种都在。 但收尾又集体滑成同一个动作——六段以「所以判断……看……」「值得问的不是 A 而是 B」收尾， 与上一轮被抓的「五段以『所以你可以问一句』收尾」是同一个动作换了皮。 另外 沟通-08 的收尾直接写成了做法建议（"有一个不需要成本的做法能解决大半"），踩了本模块红线。

    规律已经很清楚了：段落的开头容易记得换，段落的结尾总是滑回同一个手势。 → 下次统写第四段，先单独把十段的最后一句列出来看，这一步要单独做一次，不能包含在"检查骨架"里。

    第五次实测（25 职场模块）：十种骨架都立住了，问题换到了别处。

    这一轮预设的十种骨架（词义／词的缺位／传导链／空间形状／两图对照／媒介属性／数量读数／频率强度／存量／古语误读） 审稿判定八种真不同、一组重复（07 数会议次数、08 数「特殊情况」次数，是同一个招式）。

    但真正被审稿抓住的是两件别的： - 六段的标题是「四、全球与中国」，内容里没有任何中国 —— 名实不符。已逐段补上本土语境 （责任书与逐级负责、编制职称、指标的责任化、书面材料的表态性、会议的"赋予效力"、标语与落差）。 - 描述完结构顺手补一句处方 —— 「这三种对应的改善完全不同：补记录、理授权、定规则」。 这正是本模块红线，而且是在我反复强调之后发生的。

    → 教训：标题承诺了什么，就得写出什么。「全球与中国」不是第四段的默认标题， 写不出中国内容就不该用这个骨架。

    第六次实测（10 艺术模块）：给每段一个「具体的物」，结果做出了九段同一个骨架。

    这一轮我换了个思路：不再按"功能类型"分，而是给每段配一个具体的东西当锚点—— 招生简章、教材目录、手卷、展签、画册、橱窗、碑。以为物件各不相同，段落自然就不一样。

    审稿判定：6/10 是同一个骨架——「一个具体的物 → 揭示一个机制 → 一句加粗金句」， 其中四段连句法都同构（「[一个具体的物] + [它在这里的处境 / 与另一处的差别]」）。 另有两段（02、03）同属祈使式（「从……看起」「找一本……翻目录」），连动作和对象都一样。

    「给每段一个具体的物」这个指令，本身就是骨架制造机。 指令单一化，骨架就单一化——换的是锚点，语法一动没动。 这是「换的是素材，不是语法」的第三次复发（22 教育模块已记过一次，24 沟通模块收尾手势那次是它的变体）。

    这一轮还抓到两个新层次： - 十段的收尾金句全部挤在同一个语法上。「不是 A，是 B」用了 4 次，「X 决定 Y」用了 3 次。 单看每一句都成立，连着读完，金句之间互相抵消。 → 下次统写第四段，把十段的加粗句单独抽出来排一遍，看句法有几种，这一步和"抽首句""抽末句"是三件事。 - 「全球与中国」名实不符第二次复发（25 职场模块已记过一次）。这次 06 / 07 / 10 三段里没有一个中国。 这条已经复发两次，不该再当教训记，要进检查清单。

    第七次实测（11 音乐与电影）：骨架十种全换对了，但「中国」那一半是编不出来的。

    这一轮四项检查全跑了：十段骨架确实十种不同，首句十种，末句只有一段用金句收尾， 「不是 A，是 B」从上一轮的 4 次压到 2 次。形式上过关了。

    但审稿一查内容，判得比前六轮都重：10 段里 7 段不合格，3 段完全没有中国。

    根因被审稿一句话点破：我把「制度差异」换成了「这个词在中文里怎么用」。 音乐-04 讲"音响行话与制作层对不上"、音乐-06 讲"版权与著作权两个词"、电影-02 讲"定档 / 上映 / 上架"—— 这些是译名观察，不是制度观察。 词义观察本身有内容，但它替代不了「这套装置在中国是怎么装起来的」。

    为什么我会一次次滑进去： 真实的制度差异需要具体知识——演出要走报批、影展在做创投、片头分出品与联合出品、简谱在中小学课本里。 这些都得去查、去确认。 而词义观察只需要语言直觉，语言直觉我随时都有。 于是每一段都自动滑向最容易够到的那一层，而且滑得很像样——读起来不像偷懒，像有洞见。

    → 高重叠模块统写第四段时，先问一句：这一段里有没有一个具体的机构、流程、或文书？ 只有词，没有机构，就是没写到位。

    这一轮还抓到两根硬错，形态是同一个：对仗冲动。

    卡 写成了 错在哪
    音乐-01 「平均律是复调音乐的技术前置条件」 时序反了。复调在平均律通行之前就已高度发达。为了把"工具反过来规定实践"讲得漂亮，编了一条因果
    电影-04 「分级 / 审查 / 行业自律 = 三种处理方式」 归类错了。前两者回答"规则做什么"，第三者回答"谁定、有没有强制力"，两个轴正交，压不成三选一

    上一轮的对仗冲动是「在两个东西之间比出一个高低或先后」，这一轮是「为了排成三样，把不同层的东西并列」。 同一个冲动，换了个方向。凡是为了让句子齐整而增减一项的地方，都是高危区。

    审稿这一轮还量化了三件全模块级别的同构，都不是统写段的问题：

    • 「三、它怎么运转」的末条一律是"它的代价"（10/10），9/10 用「第一、第二、第三」编号。十张卡的三段骨架完全同构。
    • 「六、常见误区」30 条全是「误区N：以为 X 是 Y。」（30/30，每卡正好三条）。
    • 「不是 A，是 B」全模块 32 次（未加粗），加粗句里还有 11 处。逐句都成立，连读就是一副嗓子。

    这三条是卡片模板层面的同构，从第一个模块一路带到现在。 已写进 卡片模板.md：十张卡里至少三张要把"代价"挪出编号序列、把误区句式改出差异。 模板级的毛病，靠每次临场注意是修不掉的。

    第八次实测（13 文学与经典）：制度含量上去了，锚点却撞了。

    上一轮的标准是「每段必须落在一个具体的机构、工序或文书上」。这一轮照办， 结果显示制度含量从 3/10 达标升到 7/10——教学大纲、分类下拉菜单、版权页、投稿链、 语文课标、腰封、签约条款，都是真的东西。

    但冒出一个新毛病：锚点复用。 - 03 读版权页、09 读腰封——两段的动作完全一样：在书的实物表面找一块印刷面，读上面写了什么。 - 02 取平台的分类菜单、10 取平台的结算条款——两段的论点几乎一样：平台的某个设置，在写作开始之前就规定了写作。

    十段各有一个真实的机构，但有两对其实是同一件事做两遍。 → 检查清单加第五项：把十段的锚点列成一张表，看有没有两段用的是同一件东西。

    我自己写的三段被判不合格：04 通篇只有"稿费这个词覆盖三种计量"——只有词，没有一份合同、一个付酬主体； 08 只有"学院/媒体"两个抽象空间，没有刊物、版面、审稿流程； 05 的锚点是"书店里几个译本并排"——中国实体书店通常只进一个版本，这个场景不成立。 三条指向同一件事：标准我知道，但写的时候会自动滑向手边最容易够到的素材。

    收尾这道题，第五次换皮回来。 第 3 轮堵「判据收尾」，第 4 轮堵「你可以问一句」， 第 6 轮堵「以金句收尾」，第 7 轮堵「加粗金句 + 补一层」。 这一轮十段零金句收尾——但审稿数出来：9/10 段用转折或因果连词收尾（所以 ×3、于是 ×1、而 ×5、「不是A是B」×2）。 另外「两边都成立、不好说谁好」的免责句在 01/06/07/08 出现 4 次，位置几乎一样（对照之后、结论之前）。

    → 收尾这件事，堵住一种形态，它就从另一种形态回来。不能靠"这次注意一下"，只能靠每次换一种。 下次统写第四段，先给十段各指定一种收束方式（平陈述 / 设问 / 反例 / 代价 / 数字关系 / 引一句），不许重复。

    第九次实测（15 宗教与信仰）：同一个毛病，在第四段上连犯三次。

    11 音乐、13 文学、15 宗教——三轮的 §四 都被审稿判过同一个病： 把「制度差异」写成「这个词在中文里怎么用」。

    最刺眼的是 15：13 那一轮我已经把这条警告写进 卡片模板.md 的 §四 段落了，15 还是照样犯。 十段里 6 段以"中文里这个 X"起头，10 段全切中国，5 段用同一个「所以……先问」收尾。

    结论：把教训写进模板，并不能阻止自己再犯。 要靠的是能机械执行的检查，不是记性。

    → 新增一条可数检查（写进 卡片模板.md）：统写第四段之前，先给十段各写一句话的"锚点"， 如果锚点里没有「一个机构 / 一份文书 / 一道工序」，这一段就重来。 数一下：以"中文里的某个词"起头的段数 不得超过 3 段。

    这一轮补上的三个替换是：01 落到道教在谱系里的位置（道藏、教职）；02 落到城隍的敕封等级（府州县按行政层级排）； 09 落到宗教婚礼与法律登记的两步流程。三段改完，制度含量才立住。

    这一轮审稿还抓到一根我自己写的硬错：历法归属。

    宗教-08 我写「清明、中元、冬至、年节和二十四节气绑在一起，所以在公历上基本固定」。 中元是农历七月十五、年节是农历正月初一，都按月相，在公历上会漂一个月。 而清明、冬至才是节气（按太阳黄经）。 更糟的是卡片 §一 自己刚把这条常识写对了，§四 却写反了——同一张卡里，我的统写段落和数据段互相打脸。

    → 教训：统写段落要和卡片正文对一遍同一件事的说法。 之前几轮抓的是跨卡矛盾，这一轮是卡内跨段矛盾， 而它比跨卡矛盾更容易漏——因为统写的人是另一个人（我），写的时候没重读 §一。

    第十轮实测（28 数字素养与 AI）：技术类模块的第四段，整段的支点会塌。

    前面几轮 §四 的错是"写得虚"（只有词没有机构）。这一轮的错更深一层：两段的支撑事实本身是错的。

    • 04 我把大模型的词元化写成了"中文没有空格所以要分词"。错了——词元化用的是子词算法，和空格无关，英文生僻词一样会被拆。整段每一句都建在这个错支点上。
    • 08 我写了三条"中文关键词匹配的两难"，其中第一条要求先切词再比、第二条要求不切词直接子串匹配。两条只在互相矛盾的设定下才各自成立，而现实中大多是直接子串匹配——所以第一条根本不发生。

    共同点：它们都在"拿一个熟悉的概念去解释一个不熟悉的技术"，而那个概念（分词）本来就不适用。 → 技术类模块统写第四段前，先把那一段要依赖的技术前提单独写出来，问一句"这个前提成立吗"。 写一个漂亮的结构，比写对一句技术事实容易得多——所以会不自觉地往结构那边滑。

    另一处新错型：自拆台。 10 我写"改过的图没有痕迹可言"，而这张卡的整个结论恰恰是"要另找一层工具去查"。 这与 15 宗教那轮的"卡内跨段矛盾"是同一族——统写的人在另一段，写的时候没回头看这张卡自己的结论。

    统写第四段的四项检查（现已固定，缺一项就会漏）

    1. 十段首句并排看 —— 有几种句式？
    2. 十段末句并排看 —— 有几种收束动作？（问句 / 判据 / 代价 / 平收）
    3. 十段骨架并排看 —— 是不是都在"一个具体的物 → 一个机制 → 一句金句"？
    4. 十段加粗句并排看 —— 句法有几种？

    外加一条硬检查：每一段的标题写着「全球与中国」，就必须真的有一个中国（或一个"本地 vs 别处"的具体差异）；写不出来，就换标题或换骨架，不许空着。

    高重叠模块怎么写（2026-11-11 首个实测：10 艺术与审美）¶

    B 档剩下五个模块都与 读万卷书 / 观万部影 / 自我探索 大面积重叠。艺术是第一个，打法记在这里。

    一、查重放在最前面，而且要在写导读之前。 先核对已有内容覆盖了什么，再决定这个模块讲什么。艺术的做法是把问题切成三段：

    层 归属
    判断（好不好、算不算杰作、美是主观客观） 自我探索 6.2，本模块不碰
    具体作品与艺术家 读万卷书《艺术的故事》《美的历程》《观看之道》《谈美》
    系统与坐标（由什么构成、怎么运转） 本模块

    审稿结果：与 6.2 撞车只有 3 处，且全部集中在 §六「常见误区」——判断层的结论被当成系统层的误区写了。

    → 高重叠模块的统一口径：§六 的误区只许写「过程 / 装置被误认成什么」（以为分期是事实、以为一级市场也在炒）， 不许写「评价被搞错了」（以为价格反映水平、以为看不懂就是退步）——后者正是 自我探索 那一层的内容， 写在这里就是重复，而且会把卡片拽回判断层。

    二、跨卡一致性要单独查一次。 十张卡一起读才能发现的问题，单卡审稿永远看不见。艺术这轮最硬的一处是： 艺术-07 说「艺术品独一无二」，而 艺术-02 / 艺术-06 的核心论点都是「版画是复数性的原作、摄影按版次有多份真原作」——两张卡直接相反。 修法是把"独一无二"换成"不可替代"：有多份，但任一份都不能被另一份顶替。

    → 高重叠模块必做的最后一项检查：把同一模块里反复出现的那个关键词抽出来，逐卡对一遍定义。 （艺术是"原作 / 复制 / 独一无二"；文学会是"读懂 / 经典"；历史会是"文明 / 进步"。） 同一个词在各卡之间口径不一，比单卡写错更难被发现，也更有害。

    三、我自己写错的四处，形态完全一样。 这轮我统写九段第四段 + 标杆卡，审稿抓到四处错：

    卡 我写的 错在哪
    08 「"看不懂"在本地出现的频率比产地高」 没有依据的频率比较
    09 「本地在这一块起步晚一些」 没有依据的时序比较
    10 「有些碑立的地方，十几年前是别的样子」 变相的精确年份
    04 金句「形式不是画完才配上去的壳」 与上一句"装裱"自相矛盾

    四处里三处是同一个毛病：为了让段落有力，在两个东西之间比出一个高低或先后，而这个比较没有依据。 第四处是金句比论证跑得快——句子赢了，逻辑输了。

    → 统写第四段时逐段问一句：这段里的比较级和时序词（更、比、晚、早、先于、之后）有没有依据？ 没有就删掉比较，只留机制。机制本身通常已经足够有力，比较多半是装饰，而装饰会出事。

    30-饮食与健康 是怎么来的（2026-11-11 新增）¶

    它不是底稿里原有的 29 个模块之一。起因是一次追问：「饮食与健康这个模块，大纲里有吗？」

    查下来是真空： - 23-健康与医疗素养 建模块时主动把「营养与代谢」列进了未展开——理由是这一块观察性研究占绝对主导、 混杂几乎排除不掉，需要单独的证据纪律； - 而 01 餐桌与美食 讲的是饮食作为文化（菜系、礼仪、餐厅），不含营养。

    三个决定：独立建模块 / 证据与机制为主 / 编号 30 排 B 档最前。

    它和 23 的关系是递进而不是重复：23 讲"这点证据撑不撑得住"，30 讲"这一块为什么特别撑不住"。
