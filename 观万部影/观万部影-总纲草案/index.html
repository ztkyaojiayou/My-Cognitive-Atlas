    观万部影 · 总纲草案（v2）¶

    电影是人类如何讲述世界。

    本版在 v1（60 部 / 12 分类）基础上全面重构，采纳并整合了《ChatGPT-百年电影整理》（见同目录）的完整体系。 v1 的根本问题是：按"类型"分类。而类型是发行商的语言，不是认知的语言。

    0. 这一版改了什么¶

    v1 草案 v2 总纲
    分类维度 12 个类型式分类（自我与身份/爱与亲密…） 问题轴为主（八大文明主题）+ 时间轴 + 文明轴 + 作者轴
    选片方式 拍脑袋挑 60 部 500 部母库 → 200 → 100 必看 → 第一批 29
    电影史 无 独立成章：1895 → 2020s
    国别 只在片单里零散分布 文明×问题矩阵，每个文明问"它最爱讨论什么"
    导演 无 独立成章：导演画像 + 导演之间的对话
    解读结构 12 项（照搬书籍模板） 七段式：名片 → 故事 → 人物场景 → 为什么伟大 → 人类问题 → 认知连接 → 一句话记住
    篇幅 ≥150 行 2500–6000 字（高密度，不高篇幅）
    阅读分层 无 三级阅读 + "建议亲自观看程度"

    一句话交接：v1 是"一份片单"，v2 是"一套看电影的坐标系"。

    一、模块定位¶

    观万部影 是认知体系的输入端，与 读万卷书 平行。

    读万卷书 观万部影
    材料 书 影像
    追问 这本书帮我们理解了什么世界问题？ 这部电影让我们看见了人的哪一面？
    特长 论证、体系、概念 体验、时间、视听、共情
    模型 可复用的思维模型 可复用的影像模型

    与 自我探索 第六卷（电影与影像 10 问）的分工：

    入口 追问
    自我探索·第六卷 困惑 电影为什么让我们哭？镜头如何操纵立场？
    观万部影 作品 这一部讲了什么、怎么讲的、为什么值得人类记住？

    问题维度与作品维度，互补而不重复。

    二、核心方法论：不按类型分，按问题分¶

    类型（爱情片、科幻片、黑帮片）是工业与发行的分类。 用类型建体系，最后会得到一堆"类型知识"，而不是"理解人的坐标系"。

    所以本模块有四条轴，任何一部电影都能同时被四条轴定位：

                       一部电影
                       │
        ┌──────────┬───┴───┬──────────┐
        ↓          ↓       ↓          ↓
      问题轴      时间轴   文明轴     作者轴
       (主)      电影史   国别/地区   导演
        │          │       │          │
   它在问什么   它何时出现  谁在拍     谁拍的
        │          │       │          │
        └──────────┴───┬───┴──────────┘
                       ↓
                  我的认知

    四张地图¶

    地图 回答 本文档章节
    ① 电影史 电影是怎么发展的？ 第五章
    ② 世界电影 不同文明在拍什么？ 第四章
    ③ 人类问题 电影到底在讨论什么？ 第三章
    ④ 我的认知 这些故事最终改变了我什么？ 第七章 ⑥ 认知连接

    关键原则：电影不是孤立的。 《教父》《花样年华》《寄生虫》之所以出现，都是特定文明阶段的产物——时间轴解释了"为什么是它"。

    三、八大文明主题（问题轴）¶

    这是选片和写作的主干。每部电影先归到一个主题，再用另外三条轴补充。

    第一章：自我 —— 我是谁？¶

    核心问题： 身份、自由、孤独、自我实现、社会规训。

    第一梯队（必写） - 《楚门的世界》（1998，美国）——你的人生，有多少是被安排好的？ - 《搏击俱乐部》（1999，美国）——社会要你成为的人，和你心里那个人打架会怎样？ - 《黑天鹅》（2010，美国）——为了成为"最好的"，一个人愿意毁掉自己多少？ - 《心灵捕手》（1997，美国）——天才的痛苦，是他不知道自己值得被爱？ - 《出租车司机》（1976，美国）——一个被城市异化的人，如何把孤独变成暴力？

    备选 - 《死亡诗社》（1989）、《美丽心灵》（2001）、《穆赫兰道》（2001）、《一一》（2000）、《当幸福来敲门》（2006）

    第二章：爱与关系 —— 人与人为什么连接，又为什么分离？¶

    核心问题： 爱是什么？喜欢与爱的区别？亲密与独立？

    第一梯队（必写） - 《爱在黎明破晓前》（1995，美国）——两个人只聊一整夜，为什么能讲完一生的亲密？ - 《花样年华》（2000，香港）——在中国式的克制里，感情怎么被说出口、又怎么被收回？ - 《婚姻故事》（2019，美国）——爱是怎么在"讲道理"的过程里被一点点拆掉的？ - 《蓝色情人节》（2010，美国）——爱是在哪一刻开始不够用的？ - 《暖暖内含光》（2004，美国）——如果能删掉一段记忆，痛苦就消失了吗？

    备选 - 《重庆森林》（1994）、《卡萨布兰卡》（1942）、《泰坦尼克号》（1997）、《她》（2013）、《一次别离》（2011）

    第三章：家庭 —— 我们为什么爱家人，又为什么被家庭束缚？¶

    核心问题： 亲情、代际、父母、传统、现代化、家庭责任。

    第一梯队（必写） - 《教父》（1972，美国）——一个想逃离家族的人，为什么最终成了父亲那样的人？ - 《东京物语》（1953，日本）——子女不是不爱，为什么老人还是被"剩"下了？ - 《饮食男女》（1994，台湾）——一张饭桌上，中国家庭如何用"吃"说清一切？ - 《一一》（2000，台湾）——一家三代人，各自在生活的哪一层迷路？ - 《活着》（1994，中国大陆）——一个人被时代反复碾压，还能靠什么活下去？ - 《小偷家族》（2018，日本）——没有血缘的关系，能不能叫"家"？

    备选 - 《步履不停》（2008）、《伯德小姐》（2017）、《米纳里》（2020）、《美国丽人》（1999）、《东京奏鸣曲》（2008）

    第四章：社会与阶级 —— 人与人为什么不平等？¶

    核心问题： 阶级、贫富、制度、尊严、社会流动。

    第一梯队（必写） - 《寄生虫》（2019，韩国）——阶级不是"看不见"，是看不见彼此怎么活。 - 《燃烧》（2018，韩国）——愤怒为什么在年轻人心里烧起来？ - 《小丑》（2019，美国）——一个人被社会一点点推出边缘，会变成什么？ - 《十二怒汉》（1957，美国）——一个人的坚持，能不能掀翻一屋子人的共识？ - 《无间道》（2002，香港）——身份被制度分配之后，人还剩什么？

    备选 - 《美国往事》（1984）、《窃听风暴》（2006）、《悲惨世界》（2019）、《盲山》（2007）、《上帝之城》（2002）

    第五章：权力与政治 —— 谁拥有权力？权力如何腐化人？¶

    核心问题： 国家、权力、法律、民主、独裁、官僚体系。

    第一梯队（必写） - 《教父》（1972，美国）——权力是为了保护家庭，还是最终吞噬家庭？ - 《V 字仇杀队》（2005，美国/英国）——一个人对抗体制，有胜算吗？ - 《窃听风暴》（2006，德国）——权力体系里，一个人能否选择不做帮凶？ - 《总统班底》（1976，美国）——两个人如何扳倒一个总统？ - 《辩护人》（2013，韩国）——普通人什么时候开始"不得不"站出来？

    备选 - 《华尔街》（1987）、《辛德勒的名单》（1993）、《1984》（1984）、《杀人回忆》（2003）、《熔炉》（2011）

    说明：《教父》《辛德勒的名单》同时属于多章——这正是"一部电影可被多条轴定位"的意思。

    第六章：战争与文明 —— 人为什么会互相杀戮？¶

    核心问题： 战争是谁发动的？普通人为什么参与？文明为什么会走向野蛮？

    第一梯队（必写） - 《现代启示录》（1979，美国）——为什么最强大的工业文明会造出如此巨大的战争机器？ - 《全金属外壳》（1987，美国）——军队如何先把人变成工具，再变成机器？ - 《辛德勒的名单》（1993，美国）——一个人能救多少人？又为什么只救了那么少？ - 《西线无战事》（1930，美国）——战争对一个年轻人做了什么？ - 《拯救大兵瑞恩》（1998，美国）——用八个人换一个人，值吗？

    备选 - 《细细的红线》（1998）、《黑鹰坠落》（2001）、《帝国的毁灭》（2004）、《鬼子来了》（2000）、《自己去看》（1985）、《钢琴家》（2002）、《东京审判》（2006）

    第七章：科技与未来 —— 技术让人更自由，还是更不自由？¶

    核心问题： 当机器开始拥有智能，人还剩下什么？

    第一梯队（必写） - 《2001 太空漫游》（1968，美国）——人类的进化，和工具的进化，谁在推谁？ - 《银翼杀手》（1982，美国）——"像人"和"是人"，差别在哪？ - 《黑客帝国》（1999，美国）——如果虚假的世界让你幸福，你还愿意知道真相吗？ - 《她》（2013，美国）——如果对方不是人，爱的条件是什么？ - 《机械姬》（2014，英国）——AI 通过图灵测试之后，我们该怕的是它，还是我们自己？

    备选 - 《终结者》（1984）、《少数派报告》（2002）、《人工智能》（2001）、《攻壳机动队》（1995）、《降临》（2016）、《月球》（2009）

    第八章：死亡、意义与存在 —— 人为什么活着？¶

    核心问题： 死亡、虚无、意义、信仰、记忆、告别。

    第一梯队（必写） - 《海边的曼彻斯特》（2016，美国）——有些悲伤，是不是永远走不出来？ - 《美丽人生》（1997，意大利）——在绝对的地狱里，人还能给孩子造一个游戏吗？ - 《七宗罪》（1995，美国）——如果恶有体系，正义还剩下什么？ - 《天堂电影院》（1988，意大利）——一个人要离开故乡多远，才看得懂它？ - 《遗愿清单》（2007，美国）——如果只剩半年，你会去过怎样的人生？

    备选 - 《死亡诗社》（1989）、《活着》（1994）、《东京物语》（1953）、《霸王别姬》（1993）、《百万美元宝贝》（2004）、《生命之树》（2011）

    八个主题之间的关系¶

            自我（我是谁）
           │
     爱与关系（我和另一个人的连接）
           │
        家庭（我从哪里来）
           │
    社会与阶级（我被放在哪里）
           │
    权力与政治（谁在决定我的位置）
           │
    战争与文明（当这一切崩塌）
           │
    科技与未来（这一切将被什么改变）
           │
    死亡与意义（一切之后，还剩什么）

    从"我"出发，一圈圈推到"人类"，最后落回"意义"——这正好对应 自我探索 六卷的弧线：自我 → 他人 → 社会 → 文明 → 科学 → 艺术。

    四、世界电影地图（文明轴）¶

    不要问"美国电影有多少部"，要问"这个文明在电影里最爱讨论什么"。 以下是入口，不是结论。

    文明/地区 最常讨论的问题 代表片目
    🇺🇸 美国 个人与自由：我能不能成为自己？ 教父 / 出租车司机 / 肖申克的救赎 / 楚门的世界
    🇯🇵 日本 家庭、秩序与孤独：人如何在关系与秩序中生活？ 东京物语 / 七武士 / 小偷家族 / 步履不停
    🇰🇷 韩国 阶级、家庭与社会压力：人为什么逃不开自己的位置？ 寄生虫 / 燃烧 / 杀人回忆 / 辩护人
    🇨🇳 中国大陆 个人与时代：个人如何面对时代？ 活着 / 霸王别姬 / 盲山 / 阳光灿烂的日子
    🇨🇳 台湾 家庭、历史与成长 一一 / 牯岭街少年杀人事件 / 悲情城市
    🇭🇰 香港 城市、身份、速度、漂泊 重庆森林 / 花样年华 / 无间道
    🇫🇷 法国 个人与社会、爱情、思想（甚至问"电影应该是什么"） 四百击 / 广岛之恋 / 去年在马里昂巴德
    🇮🇹 意大利 普通人的生活 偷自行车的人 / 罗马，不设防的城市 / 八部半 / 美丽人生
    🇩🇪 德国 现代性、战争、罪责、身份 帝国的毁灭 / 窃听风暴 / 大都会
    🇸🇪 北欧 存在主义：上帝在哪？人为什么孤独？ 第七封印 / 野草莓
    🇮🇳 印度 家庭 + 宗教 + 阶级 + 社会结构 大地之歌 / 三傻大闹宝莱坞 / 摔跤吧！爸爸
    🇮🇷 伊朗 在限制中，用最日常的故事谈道德与社会 一次别离 / 小鞋子
    🌎 拉美 贫困、阶级、暴力、殖民历史 上帝之城
    🌍 非洲 殖民、身份、现代化（数量少但不可缺） 黑女孩 / 廷巴克图

    为什么必须做国别轴： "经典电影"从来不是一份中立名单，而是一套"谁有资格进入经典"的评价体系。只做美国片，等于把好莱坞的品味当成世界史。

    五、电影史时间轴¶

    一部电影为什么长这样，一半答案在它的时代里。

    1895  电影诞生（卢米埃尔兄弟）
  ↓
1910s–20s  默片时代 · 卓别林 · 德国表现主义 · 苏联蒙太奇
  ↓
1930s–40s  好莱坞黄金时代 · 类型片成型 · 二战与美国电影
  ↓
1950s  日本电影黄金时代（黑泽明/小津）· 意大利新现实主义
  ↓
1960s  法国新浪潮 · 作者电影 · "电影应该是什么"
  ↓
1970s  美国新好莱坞 · 科波拉/斯科塞斯/库布里克
  ↓
1980s  商业大片时代 · 斯皮尔伯格 · 香港电影黄金期
  ↓
1990s  独立电影 · 全球化 · 华语电影崛起
  ↓
2000s  数字电影 · 大片与系列化
  ↓
2010s  流媒体 · 超级英雄 · 韩国电影走向世界
  ↓
2020s  AI · 虚拟制作 · 算法分发

    用法： 每部电影的 ②「时代与作者」都要能回答"它为什么在这个时间点出现"。 例如：《教父》为什么出现在 1972？——新好莱坞、移民史、黑帮神话的黄昏。

    六、母库分层与第一批开写¶

    不一开始就定 100 部¶

    电影比书更适合做母库：

    Level 4  扩展片库（∞）
   ↑
Level 3  500 部「世界电影母库」   ← 建立地图
   ↑
Level 2  200 部重要经典
   ↑
Level 1  100 部「认知必看」        ← 深度解读

    怎么选 100 部？ 不拍脑袋，用共识矩阵交叉筛选：

    奥斯卡 · IMDb / Letterboxd · Sight & Sound · AFI · 戛纳/威尼斯/柏林 · 电影史教材 · 导演与影评人 · 各国电影史 · 中国观众的语境

    交叉之后仍站得住的，才是"真正跨越时代、跨越国家、跨越评价体系"的经典。

    第一批：29 部（8 主题 × 3 核心 + 5 部华语补位）¶

    推进方式（已定稿）：横切——8 个主题各先立 3 部，体系骨架先成形，再回头补厚。

    主题 核心 3 部 华语补位
    自我 楚门的世界 · 搏击俱乐部 · 黑天鹅 —
    爱与关系 爱在黎明破晓前 · 花样年华 · 婚姻故事 —
    家庭 教父 · 东京物语 · 饮食男女 活着 · 一一
    社会与阶级 寄生虫 · 燃烧 · 十二怒汉 无间道
    权力与政治 窃听风暴 · 辩护人 · V 字仇杀队 —
    战争与文明 现代启示录 · 全金属外壳 · 辛德勒的名单 鬼子来了
    科技与未来 2001 太空漫游 · 银翼杀手 · 黑客帝国 —
    死亡、意义与存在 海边的曼彻斯特 · 美丽人生 · 天堂电影院 霸王别姬

    总账： 29 部 = 核心 24 + 华语补位 5；其中华语片 7 部（花样年华 / 饮食男女 / 一一 / 活着 / 无间道 / 鬼子来了 / 霸王别姬），占 24%。

    为什么这样补： 这套体系有一根"中国认知坐标"的横轴，第一批若只有 2 部华语，"世界电影地图"会退化成一个外国片单。补位不是凑数——五部补位片正好咬住家庭（活着、一一）、阶层（无间道）、战争（鬼子来了）、意义（霸王别姬）这几个中国经验最锋利的切面。

    开写顺序（已定稿）： 从 《活着》 起手（家庭主题 · 华语补位 · 第五代代表作），先立标杆再铺开。

    七、解读模板（七段式）¶

    原则：高密度，不是高篇幅。 普通电影 2500–4000 字；核心经典 4000–6000 字；极少数文明级作品 6000–8000 字。

    01｜电影名片（约 200 字）¶

    年份 · 国家 · 导演 · 主演 · 类型 · 时代背景 + 一句话说明它为什么值得看。

    示例： 《教父》｜1972｜美国｜弗朗西斯·科波拉 表面讲黑帮，实则讲家庭与权力继承。它最核心的问题不是"黑帮有多残酷"，而是：一个原本想逃离父亲的人，为什么最终成为了父亲？

    02｜故事（800–1500 字）¶

    按 开端 → 冲突 → 转折 → 高潮 → 结局 讲，不逐场复述。 允许剧透——目标是"即使没看，也知道发生了什么"。 保留那些改变人物命运的细节。

    03｜关键人物 + 关键场景（500–800 字）¶

    只抓 3–6 个核心人物、3–5 个关键场景。 每个场景只回答两件事：发生了什么？为什么重要？

    04｜为什么它伟大？（500–1000 字）¶

    电影学层面：导演手法 / 表演 / 摄影 / 剪辑 / 音乐 / 叙事结构。 原则：每一个技术点，都必须服务于"这部电影为什么特别"。 不是电影语言教材。

    05｜进入人类问题（800–1200 字）¶

    只抓 1–3 个核心问题（如《教父》：权力 / 家庭 / 道德）。 每个问题分三层问： - 电影给出了什么答案？ - 这个答案有什么局限？ - 我们今天怎么看？

    06｜认知连接（300–500 字）¶

    把它接进整个体系： 电影 → 主题 → 相关书 → 哲学/社会学理论 → 现实

    最后留 3 个值得思考的问题。

    07｜一句话记住（约 50 字）¶

    收尾金句。要求同《自我探索》291 问的 ⑦： 一句话说完，能带走，能在多年后突然想起来。

    示例（《活着》）： 人不是为了什么大道理活着的——是为了"下一顿饭、下一个人"活着的；命运拿走了所有理由，活着本身就是最后一个理由。

    加这一段的好处：全模块的金句可以直接汇总进《我的世界观》式输出层，电影线与自我探索线在同一处汇合。

    八、五层叙事：故事要讲清楚¶

    写作前先完成"故事还原"，再进入分析。先还原电影，再解释电影，最后超越电影。

    1. 一句话：它讲什么
    2. 人物关系图：谁和谁是什么关系
    3. 完整剧情：按电影时间线（第一幕冲突 → 第二幕升级 → 第三幕转折 → 第四幕选择 → 第五幕高潮 → 第六幕结局）
    4. 关键场景：3–5 个
    5. 细节：那些只有注意到才懂的镜头、道具、色彩

    九、三级阅读与"亲自观看程度"¶

    每部电影标注建议亲自观看程度：

    • ★★★★★ 必须亲自看（影像本身不可替代：如《2001 太空漫游》《花样年华》）
    • ★★★☆☆ 时间有限可以先读（故事强、形式依赖低）
    • ★☆☆☆☆ 先了解即可（影史意义大于观看体验）

    对应的三级阅读：

    层级 时间 内容
    Level 1 5 分钟 名片 + 一句话 + 3 个思考问题
    Level 2 20 分钟 + 故事 + 关键人物场景
    Level 3 深度 全篇

    这让"100 部"变成可完成的计划：5 分钟能过一遍，20 分钟能懂一部，深度阅读留给真正重要的那些。

    写作规范：

    • 每部按六段式，六段齐全
    • 语言沿用整套体系的"呼吸感"：短句、单行成段、每部 2–4 处加粗金句
    • 敬慎题材（战争、制度、历史）只解释机制，不做政治表态，不整体评判任何群体
    • 每部写完，在 README.md 进度表标记 ✅
