    《从 0 到 1》· 彼得·蒂尔¶

    Zero to One, Peter Thiel with Blake Masters, 2014

    ① 它在讲什么¶

    彼得·蒂尔是 PayPal 的联合创始人、Facebook 的第一个外部投资者。在这本书里，他没有写"怎么开公司"的操作手册——他在问一个更深的问题："有什么重要的事是几乎所有人都不认同——但你是对的？"

    他的答案是：真正的创新不是从 1 到 n——复制已有的、扩大规模。真正的创新是从 0 到 1——创造以前不存在的、定义一个全新的领域。 垄断不是坏事——当它来自创造了独一无二的技术时。竞争是给失败者准备的——它把所有玩家的利润压缩到零，并让人沉迷于打败别人——而不是创造新东西。

    这本书不是创业手册——它是一份关于"创造"本身的哲学宣言。

    ② 历史背景¶

    2014 年，硅谷处于科技泡沫和独角兽狂潮之中。蒂尔在斯坦福开了一门创业课——学生笔记在网上爆炸式传播，最后成了这本书。他的风格是挑衅的——他不是来夸"更多创新""更多创业"——他是来打脸：过去几十年真正的"从 0 到 1"几乎没有——人类在原子世界停滞了，只在比特世界里看似繁荣。

    蒂尔本人是硅谷的"反叛者"——他投资 Facebook 时所有人都不看好，他公开说"竞争是给失败者的"。这本书带着一种罕见的诚实：大多数所谓的"创新"，只是把别人的创新换个包装再卖一遍。真正的从 0 到 1，极其罕见。

    ③ 核心思想与观点¶

    3.1 从 0 到 1 是创造，从 1 到 n 是复制¶

    蒂尔说，如果你造了一台和上一台一样的打字机——那是从 1 到 n。如果你造了一台文字处理器——那是从 0 到 1。复制已有的东西让人舒服——因为你知道市场存在、需求存在。但你只是在已有的蛋糕上抢份额。 真正的创新是造一个新的蛋糕——做出一个没有人做的出来过的东西。

    "下一个比尔·盖茨不会造操作系统。下一个拉里·佩奇不会造搜索引擎。如果你正在复制这些人——你不是在向他们学习——你是在拷贝。"

    从 1 到 n 不是错——它创造了繁荣（中国在这方面是大师）。但从 0 到 1 才是"新"——它让世界有了以前不存在的东西。 蒂尔不是要你鄙视"复制"——他是要你看清：如果你只想做"复制"，你就永远在别人的游戏里抢第二名。

    3.2 垄断是好的——当它来自为世界创造了独一无二的价值¶

    "垄断"一词在政治和政策讨论里都是负面的——高价格、没有选择、剥削消费者。蒂尔说那不是"创造性垄断"。

    创造性垄断者——比如谷歌——不是靠"排他竞争"成功的。是因为他们做出了比任何其他搜索引擎好太多的产品、让几十亿人自愿选择。 这个"垄断"不是权力制造的——是价值制造的。政府强制的垄断和创造性垄断完全不同。

    蒂尔的尖锐之处：大多数公司假装自己在竞争（"我们处于激烈竞争的市场"），实际上在乞求垄断（"我希望能成为唯一的玩家"）。 他的建议是反直觉的：别想着"打败所有对手"——先做出一个"没有对手能做得一样好"的东西。 当你拥有垄断式的独特价值时，你不必竞争——你被需要。

    3.3 竞争是给失败者的¶

    蒂尔花了很多篇幅抨击"痴迷于竞争"的文化——不但学校排名、职场升迁、创业也是谁先上市谁赢。他说：竞争让你把所有的注意力放在隔壁桌的那个人身上——忘了外面还有一个完全没人碰的市场。

    "竞争让你变得更好——但最多是和别人一样好。它不会让你创造别人没有做过的东西。"

    竞争的悖论： 它让你"比别人强"，却永远不会让你"独一无二"。当你赢了竞争——你得到的只是一个"比别人强一点"的位置——一个很快会被更强的后来者抢占的位置。而真正的"赢"——是进入一个没人竞争的位置。

    3.4 幂次法则：一小撮东西决定一切¶

    风投回报遵循的不是正态分布——是幂次分布。蒂尔的数据：投资组合里最好的那一笔投资——会超过其他所有回报的总和。人生也一样——不是所有事情同等重要。你需要疯狂地只做那个最重要的。

    幂次法则的日常含义很刺人：你的"多任务"和"平衡"——可能正在稀释你的力量。 如果你把 20% 精力给最重要的事、80% 给一堆"应该做"的事——那个最重要的事永远成不了气候。把鸡蛋放在"最大的那个篮子里"不是赌博——是幂次法则的必然要求。

    3.5 未来需要秘密——需要相信还有未知¶

    蒂尔说，人类进步停止的根本原因不是技术难题——是人们不再相信还有秘密。 如果你认为"所有重要的问题已经都有答案了"——你就不会去从 0 建一个新的。如果你相信山那边的地下还埋着没人发现过的金矿——你就不会停止向北走。

    "秘密是那些'还没有被发现的重要真相'——它们存在。只有去寻找的人才可能找到。"

    "相信秘密存在"是创新的前提。 如果你相信"世界已经全被发现了"——你永远不会去寻找。如果你相信"一定还有没人发现的真相"——你会持续地挖。蒂尔说：多数人放弃了寻找秘密，不是因为秘密不存在——是因为寻找秘密是孤独的、不确定的、可能徒劳的。 但恰恰是这个"可能徒劳"，筛掉了大多数竞争者。

    ④ 可复用的思维模型¶

    模型一：反共识提问¶

    不要问"什么地方还有机会"。问："什么事情是你认为重要——但几乎所有聪明人都告诉你这是错的？ "从 0 到 1 的机会在反共识里。

    怎么用：拿出一张纸，写下三个"我认为对、但没人支持"的想法。不是每条都对——但那些"对却没人信"的，就是你潜在的从 0 到 1。

    模型二：竞争审计¶

    当你在追逐一个目标——停下来问自己："我是在做真正独一无二的事——还是在努力打败我旁边的人？ "如果是后者——你被锁定在从 1 到 n 的循环里。

    怎么用：对你的职业、副业、创作问一句："如果明天所有同行都消失了，我做的事还有价值吗？"如果答案是"没有"——你一直在"竞争"而不是"创造"。

    模型三：幂次优先级¶

    对这一年要做的事——找出唯一最重要的一件事。集中你的所有资源、时间和注意力在最深层的那件。不要把一周分配给一百件"我觉得都应该做的事"。

    怎么用：每年年初，只允许自己写下"今年最重要的一件事"。如果写第二件——划掉。那一件事，值得你投入其余所有事的资源。

    模型四：秘密探索¶

    对自己领域里的"公认事实"——挑一条。问："这可能只是一个我们暂时没有证据推翻的旧说法——如果它是错的，新的可能是什么？ "

    怎么用：每月一次，挑一条"所有人都认为理所当然"的行业常识，试着想一个"如果它错了会怎样"的替代方案。你不一定对——但你在练习"相信秘密存在"。

    ⑤ 洞见¶

    蒂尔不是在给"创业方法论"。他是在表达一种世界观：创造不是答案——是问题——是不断追寻那些大部分人已经停止去问的问题。 垄断不是目的——是你做对了独一无二的事之后的奖励。

    他最深的洞见是：竞争和创造是两件相反的事。 竞争让你把眼睛盯在对手身上——创造让你把眼睛盯在"不存在的东西"上。大多数人一辈子都在"竞争"——因为竞争有规则、有参照、不会太孤独。而"创造"——没有规则、没有参照、可能失败——所以大多数人逃避它。蒂尔的价值，是提醒你还有另一种活法：不是赢别人，是做出别人没做过的东西。

    ⑥ 局限¶

    蒂尔的叙述以美国软件和互联网为中心——对医疗、能源、材料等需要长周期研发和监管参与的领域——公式被过度简化。他本人的政治观点（对新自由主义政府模式的反感）渗透在书的每一个关键建议中。

    "垄断是好的"也容易被滥用——垄断者可能用资本压垮创新而非创造价值。蒂尔的"从 0 到 1"叙事对"需要大量基础研究和制度支持"的创新讨论不足——不是所有创造都发生在车库和风险投资里。

    ⑦ 如果只记住一句话¶

    "有什么重要的事是几乎所有人都不认同——但你是对的？"——找到这个问题，你就找到了从 0 到 1 的唯一入口。

    ⑧ 同一问题，其他学派怎么回答？¶

    克里斯滕森（《创新者的窘境》）：大公司不是不想做从 0 到 1——是它们的价值链和现有客户不允许。蒂尔讲"为什么需要从 0 到 1"，克里斯滕森讲"为什么从 0 到 1 如此之难"。

    塔勒布（《反脆弱》）：蒂尔说"做独一无二的垄断者"，塔勒布说"保留冗余和备选"。一个是"全力押注一件事"，一个是"别把鸡蛋放一个篮子"——两者看似矛盾，实际是不同阶段的策略：押注之前要验证，验证之后要全力。

    赫拉利（《未来简史》）：蒂尔看到的是"人类在停滞"，赫拉利看到的是"人类正被技术和数据主义替代"。一个提醒你"去创造"，一个提醒你"创造会改变人本身"。

    ⑨ 它改变了什么？¶

    "从 0 到 1"这个词已经成为了中文创业圈的日常用语——经常被用它包装各种"其实是复制已有的东西"的企划。但反过来——从 0 到 1 的独特原创精神也激励了一小批真正的创造者。

    它的真正影响不在"创业方法论"——而在于它重新定义了"创新"的含义：不是"做得比别人的好一点"（1到n），而是"做出了以前不存在的东西"（0到1）。这个区分，让一代人开始追问自己的工作和创造：你是在复制，还是在创造？

    ⑩ 最常见的误读¶

    误读一："垄断就是好的。" 蒂尔只在"创造性垄断为世界提供了独一无二的服务"这个前提下才这么说。靠政府关系、排他协议和资本压制竞争的——不是从 0 到 1，是权力寻租。

    误读二："读了这本书就能从 0 到 1。" 这本书不能给你"灵感"——它给你的是"方向"。真正的从 0 到 1，靠的是长期、孤独、可能失败的探索——不是一本书。

    误读三："竞争都是坏的。" 蒂尔说的是"痴迷于竞争"是坏的——竞争本身在大多数领域是健康的。他反对的不是竞争——是"把竞争当作目的"。

    ⑪ 对中国读者有什么特殊意义？¶

    中国的巨大优势在于从 1 到 n 是世界上最快的——从制造、到供应链、到互联网应用复制，中国是"规模化复制"的全球冠军。但随着技术和增长模式面临瓶颈——真正的压力是"下一代的源泉在哪里"。

    当一个社会习惯了从一个到一百万的复制速度——它还能不能忍受从 0 到 1 必须的漫长寂寞？这是对中国未来的核心提问。 对中国的创业者、工程师、创作者——蒂尔的价值是：他让你从"复制速度的骄傲"中抬起头，问一个更难的问题：下一个"以前不存在的东西"，会不会从你手里诞生？

    ⑫ 它可以解释哪些现实困惑？¶

    困惑一：为什么我拼命工作，却只是"别人做什么我也做什么"？ 因为你在从 1 到 n 的赛道里——复制是安全的，创造是孤独的。蒂尔会说：你不必逃出复制——但你至少该知道，你一直在复制。 清醒比麻木强。

    困惑二：为什么我总在"和同事竞争"，却感觉越来越没价值？ 因为竞争让你被对手定义——你的价值 = "比隔壁强多少"。当你把目光从"对手"移到"不存在的东西"上——你才可能创造自己的价值定义。

    困惑三：为什么我做了很多事，却没有一件"独一份"的？ 因为你在"分散投入"——幂次法则要求你"全力押注一件事"。把一百件事的 1% 收回来，押到一件事的 100% 上——那件事才有机会从 0 到 1。
