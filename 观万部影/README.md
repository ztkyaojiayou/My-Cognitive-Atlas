# 观万部影

> 通过电影理解人——影像如何讲述故事、塑造认知、表达情感。

---

## 定位

"观万部影"是认知体系的**输入端**，与 [读万卷书](../读万卷书/) 平行。

- **读万卷书**：书怎么讲人——一本本吃透，提炼可复用的思维模型
- **观万部影**：影像怎么让人看见自己——一部部深解，提炼可复用的影像模型

电影的特殊性在于：它不只讲"发生了什么"，它同时用**镜头、构图、剪辑、声音、色彩、空间**在讲。
所以解读电影，必须多一层"它是怎么讲的"。

与 [自我探索](../自我探索/) 第六卷「电影与影像」的区别：

| | 入口 | 追问 |
|---|---|---|
| 自我探索·第六卷 | 困惑 | 电影为什么让我们哭？镜头如何操纵立场？ |
| **观万部影** | 作品 | 这一部到底讲了什么、怎么讲的、为什么值得反复看？ |

问题维度与作品维度，互补而不重复。

---

## 解读框架

每部电影使用统一的观影解读模板，**必写 7 项 + 选写至少 3 项**：

```
① 它在讲什么 → ② 时代与作者 → ③ 核心思想与主题
→ ④ 影像语言与可复用模型 → ⑤ 洞见在哪里 → ⑥ 局限与盲区 → ⑦ 一句话
```

选写：⑧ 其他作品怎么回答 → ⑨ 它改变了什么 → ⑩ 最常见的误读
→ ⑪ 对中国观众的意义 → ⑫ 能解释哪些现实困惑

> 其中 **④ 影像语言** 是电影解读区别于书本解读的关键一层——它把"怎么拍的"变成"可以带走的方法"。

## 使用说明

- 每部按模板撰写：**必写 7 项全覆盖，选写至少 3 项**
- 篇幅：每部 **≥150 行**
- 语言保持整套体系的"呼吸感"：短句、单行成段、每部 2-4 处加粗金句
- 文件名：`films/<分类>-<两位序号>-<片名>.md`（如 `films/自我与身份-01-搏击俱乐部.md`）
- 每部写完后，在上表"状态"列标记 ✅
- 敏感题材（战争、制度、历史）只解释机制，不做政治表态，不整体评判任何群体
