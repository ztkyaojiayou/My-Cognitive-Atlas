# 通识指南

> 补足学校教育没覆盖、进入社会才陆续撞见的那部分知识。
>
> **不追求让人显得博学，而是让人面对陌生领域时，知道从哪里开始理解。**

---

## 定位

`通识指南` 是认知体系的**基础设施层**，与前三个模块互补：

| 模块 | 回答 | 形态 |
|---|---|---|
| 读万卷书 | 书里讲了什么 | 200 本，每本深解 |
| 自我探索 | 我的答案是什么 | 291 问，每问七段 |
| 观万部影 | 影像让我看见了什么 | 200 部，每部七段 |
| **通识指南** | **这个世界有哪些领域、怎么运转** | **卡片化，可检索** |

> 前三者给**深度**，这一份给**坐标**。

**与「自我探索」的分工要特别说清：**
自我探索回答"我该怎么想"，通识指南只回答"它是什么、从哪来、怎么运转"。
同一件事碰到时，**先查通识指南建立坐标系，再回自我探索形成判断。**

## 体例：薄卡片

前三份都是"厚文章、少数量"（每篇 5000 字）。这一份反过来：

- 目标是**查得到**，不是读得深

## 硬性纪律

1. **事实基线先行**：每个模块开写前，先写 `事实基线.md`，把易错的硬事实（年份、定义、数字、条文）列出来。**卡片只引用基线，不自行生成。**
2. **卡片 8 段齐全**，800–1500 字。
3. **不编造**：年份、数字、法条、机构名、参数——不确定就删掉该句，不换一个"看起来合理"的顶上。
4. **敏感题材**（政治、法律、宗教、历史）：只解释机制，不做政治表态，不对任何群体作整体评价。
5. **写完必跑** `python3 tools/verify_cards.py`。

> 背景：前一批（观万部影第二批）因为事实基线太粗，错误密度是第一批的 3 倍。这个模块**事实密度更高**，同样的错误代价更大。详见 `事实基线规范.md`。

### 加粗口径（2026-11-10 修订）

原来的「每卡 2–3 处加粗」太含糊，落地时各模块自己漂了：法律中位数 **16 处**、新闻 **12 处**、经济 **3 处**。
现在改成可数的两条口径，写进 `卡片模板.md`，并加进校验脚本 `--bold`：

| 类型 | 定义 | 上限 |
|---|---|---|
| 行内强调 | 句中、前面还有正文的加粗 | **2–4 处** |
| 结构性标签 | 整行起头、独占语块的加粗（`**误区一：……**`、单独成行的金句） | **≤12 处** |

16 模块是第一个按新口径写的，十张卡实测行内强调 4/2/2/2/2/2/2/2/2/2，全部合格。

> ⚠️ **历史遗留**：20-法律与法治、21-新闻与媒介素养两个模块按旧口径写成，行内强调 9–23 处不等，
> 跑 `verify_cards.py --bold` 会报出来。**暂不回溯修改**——那要动 24 张已审过稿的卡，
> 收益只是排版一致，风险大于回报。列入待办，将来重审这两个模块时一并处理。

### 第四段由主控统写（2026-11-10 起）

问题：写作 agent 各自写「四、全球与中国」，写出来必然是同一句免责套式（心理学模块七张卡同款收尾）。
办法：这一段不给写作 agent，主控一次性统写十段。

**第一次实测（18 模块）的结论：有效，但不够。**

- 有效：写作 agent 的第四段偷懒问题彻底消失，十段都有实内容
- 不够：**我在同一轮里写的九段，仍然共享同一个修辞框架**——九段里八段都是「中文里某个词偏了，所以大家误解了」。
  我换了九个切入角度，却没换掉那个壳。审稿一句话点破："九段以中文起头。"

**真正的解法不是"谁写"，是"写完并排看"。** 十段并排放进一个视图，首句并列排出来，
雷同立刻现形——这次是靠审稿 agent 做的那张首句对照表才发现的。

→ 下次统写第四段，**先列出十段的首句和收尾句并排看一遍，再动笔**。
