# 读万卷书

> 书的维度——从经典著作出发，逐本深度解读。

---

## 定位

"读万卷书"是认知体系的**输入端**。这里做的是把一本本书吃透，提炼可复用的思维模型。

问题维度的探询在 **[自我探索](../自我探索/)** 中——从困惑出发，调用多本书来回答。两条线交汇于现实困惑。

---

## 解读框架

每本书使用统一的 [解读模板](书籍解读模板.md)，必写 7 项 + 选写 5 项：

```
① 世界问题 → ② 历史背景 → ③ 核心思想与观点 → ④ 可复用思维模型
→ ⑤ 洞见与经典性 → ⑥ 局限与盲区 → ⑦ 一句话
```
