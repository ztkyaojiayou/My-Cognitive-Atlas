# 观影深解 · 写作规范（给写作 agent）

> 写任何一部之前，先读这两份：
> 1. 本文件
> 2. 标杆篇 `films/家庭-04-活着.md`（行文密度、段落长度、加粗习惯以它为准）

---

## 一、结构：严格七段，标题逐字一致

```
## 01｜电影名片
## 02｜故事
## 03｜关键人物与关键场景
## 04｜为什么它伟大？
## 05｜进入人类问题
## 06｜认知连接
## 07｜一句话记住
```

| 段 | 内容 | 篇幅 |
|---|---|---|
| 01 | 年份/国家/导演/主演/编剧或原著/摄影/配乐/获奖 + 时代背景 + 一句话"它为什么值得看" | 约 200 字符 |
| 02 | 开端→冲突→转折→高潮→结局；允许剧透；保留改变人物命运的细节；不逐场复述 | 1100–1600 字符 |
| 03 | 3–6 个人物、3–5 个场景，每场只答"发生了什么、为什么重要" | 600–900 字符 |
| 04 | **重点**：影像语言（镜头/摄影/剪辑/声音/色彩/空间/表演），每节都要收在"这片为什么特别" | 1300–1800 字符 |
| 05 | 2–3 个核心问题，每问三层：电影给的答案 / 这个答案的局限 / 我们今天怎么看 | 900–1200 字符 |
| 06 | 接进体系：主题→相关书→理论→现实，末尾留 3 个值得思考的问题 | 300–500 字符 |
| 07 | 收尾金句 | 约 50 字符 |

**全文合计约 5000–7000 字符。**

---

## 二、文件头部格式（逐字照抄结构）

```
# 《片名》｜年份｜国家｜导演

> **主题：** <主题大类> · <一句副题>
> **清单：** <主题>-<序号> ｜ <层级>
> **建议亲自观看程度：** ★★★★★（<一句理由>）

---
```

**层级只能填「核心经典」或「文明级」，以派活指令里给的为准，不得自行改。**

---

## 三、风格

- 短句为主。**单行成段**，段落最多 3–4 行。
- 每篇 2–4 处加粗金句（可以略多，但不要满屏）。
- 不堆概念；每个抽象词后面跟一个具体画面。
- 少用"深刻""震撼""细思极恐""封神"这类空词。

---

## 四、事实纪律（最重要）

1. **只用派活指令里给的"事实基线"**，加上你确凿知道的细节。
2. **不确定的画面、台词、获奖、演职员，一律不写。** 宁缺毋假。
3. 台词引用不确定时，写"大意是"，不要打引号冒充原文。
4. **引用《自我探索》的提问时，只能用真实编号**（1.1–6.4，见下），**禁止编造"贯穿轴 X 组"以外的组号**（贯穿轴只有 A/B/C/D 四组）。

可用编号：1.1 1.2 1.3 1.4 ｜ 2.1 2.2 2.3 2.4 ｜ 3.1 3.2 3.3 3.4 3.5 ｜ 4.0 4.1 4.2 4.3 4.4 ｜ 5.0 5.1 5.2 5.3 5.4 ｜ 6.1 6.2 6.3 6.4

---

## 五、敏感题材

战争、制度、历史、民族、阶层、性别等题材：

- **只解释机制，不做政治表态，不对任何群体作整体评价，不影射现实国家。**
- 暴力与创伤：写处境与后果，不渲染细节。
- 心理议题：写角色处境，不做医学诊断式断言。

---

## 六、输出

- 只写入派活指令指定的**那一个文件**，不要改动或创建其他文件。
- 完成后**只回一行**：`路径 | 字符数 | 七段齐全`。不要复述内容。
