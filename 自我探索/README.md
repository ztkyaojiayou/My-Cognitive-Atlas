---

## 五层系统架构

```
世界认知地图（问题树）      ← 为什么问这个？入口永远是问题，不是书
        ↓
思想流派地图（解释框架）    ← 有哪些不同的答案？学派对比，避免单一视角
        ↓
经典书籍库（节点资源）      ← 到哪里深入阅读？一本书可挂在多个问题下
        ↓
现实案例库（验证场景）      ← 怎么检验？放到真实世界中去验证
        ↓
个人认知模型（自己的世界观） ← 我最终相信什么？形成自己的判断
```

| 层级 | 功能 | 方向 |
|------|------|------|
| 第一层：问题树 | 以人类核心困惑为入口 | **输入**：理解世界 |
| 第二层：思想流派 | 呈现同一问题的多元解释 | |
| 第三层：经典书籍 | 深入阅读的思想资源 | |
| 第四层：现实案例 | 用真实场景检验理论 | **输出**：形成判断 |
| 第五层：个人认知模型 | 沉淀为自己的世界观 | |

# 贯穿轴：中国认知坐标（China Perspective）【待写】

> **不是「中国 vs 西方」，而是「中国经验是理解世界的一副重要眼镜」。**

中国认知坐标不单独成卷，而是**贯穿所有六大模块的横轴**。

## 在每个模块中的体现

| 模块 | 西方视角 | 中国视角 |
|------|---------|---------|
| **自我** | 个人主义："我是谁？" | 关系中的自我："我是谁，以及我属于谁？" |
| **自由** | 摆脱束缚 | 在关系中实现自我 |
| **家庭** | 个人边界优先 | 家庭责任与个人自由平衡 |
| **社会** | 制度设计 | 秩序、人情、关系网络 |
| **人生意义** | 个人实现 | 修身、齐家、责任、家国 |
| **商业与组织** | 契约 | 关系与灵活性 |

## 关键问题

- 中国传统思想（儒、道、佛）如何理解人、社会、宇宙？
- 中国为什么走上了不同于西方的现代化道路？
- 当代中国社会面临哪些独特困境？
- 如何在不失去自己文化根基的前提下，吸收世界思想？

## 写作规范

每个问题按 **`问题维度工作规范.md`** 的七段式深挖：
① 为什么困扰我们 → ② 本质 → ③ 各学派怎么回答（标注引用书）→ ④ 误区 → ⑤ 中国处境 → ⑥ 可以怎么想 → ⑦ 一句话记住

- 每个新小节开写前，先基于 README 已有问题讨论、扩展问题清单（8-12 问，宁缺毋滥）
- 每个问题都标注引用的书（→ 读万卷书/books/xxx.md）
- 语言保持呼吸感：短句、停顿、有金句，不堆砌概念
