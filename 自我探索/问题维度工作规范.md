# 自我探索 · 问题维度工作规范

## 定位

与"读万卷书"（书维度）正交。读万卷书是**资源库**（200 本已就位），自我探索是**问题维度**——从真实困惑出发，调用这些书来回答。

核心逻辑（五层系统架构）：
```
问题树 → 思想流派 → 经典书籍 → 现实案例 → 个人认知模型
```

---

## 组织方式

- 四个文件，对应"自我"卷四章：
  - `自我探索-01-我是谁.md`（自我认知）
  - `自我探索-02-我为什么会这样.md`（心理机制）
  - `自我探索-03-我真的自由吗.md`（自由与选择）
  - `自我探索-04-我为什么而活.md`（人生意义）
- 每章内：主题为 `##`，问题为 `#`（每个问题一个文件内的独立小节，一问一深挖）
- 每章末尾：累积的"我的思考"汇入一个总文件 `我的世界观.md`

---

## 每个问题的写作框架（一问一深挖）

```
# 问题：XXXXXXXX（以真实困惑命名）

## ① 为什么这个问题困扰我们？
从真实生活经验切入——这个问题如何刺痛当代人。

## ② 它的本质是什么？
拆解这个困惑——区分易混淆概念，点出深层结构。

## ③ 各学派怎么回答？
思想光谱：3-5 种立场，各附代表人物 + 代表书。
必须标注引用的书：`→ 读万卷书/books/认识自己-12-依恋.md`

## ④ 这里容易掉进什么误区？
常见误解 + 思维陷阱（很多困惑是因为用错了框架）。

## ⑤ 中国人在这个问题上的特殊处境
中国认知坐标：传统思想如何回答 + 当代中国社会如何体现。

## ⑥ 如果是你，可以怎么想？
提供思考路径，导向"个人认知模型"。不给标准答案。

## ⑦ 一句话记住
浓缩成可带走的一句。
```

---

## 硬性标准

1. ③ 各学派回答：3-5 种立场，**必须标注引用的书**（文件名 + 路径）
2. 篇幅：讲透为上，每个问题 ≥120 行
3. 语言：有洞察、有金句、落在真实生活，避免空洞鸡汤
4. ⑤ 中国处境：每个问题都要有（这是中国认知坐标的落点）
5. ⑥ 思考路径：可操作，链接到个人认知模型
