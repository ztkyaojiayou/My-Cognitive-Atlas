# 世界纪录片

> 故事片回答"我们想成为什么"，纪录片回答"**我们看见了什么，以及谁有资格被看见**"。
>
> 这份表不按"高分纪录片"排，只回答一件事：**在纪录片史上，这部片子做过什么第一次、或者把什么推到了极限。**

---

## 使用说明

- **按国别分区，年代写进每一行**。同一个导演或同一个运动跨年代，不在时代里切碎。
- 每区 5–8 部；纪录片传统薄的地区 3–4 部，**不硬凑**。
- 每部一行：片名 ｜ 年代 ｜ 一句话，说清"它做了什么"。
- 收录口径：影史公认的纪录长片为主；影响极大的系列破例，行内标"（系列）"。
- 纪律：只写影像与机制，不写国民性断言；年份、片名不确定就不写。

---

## 纪录片六个节点

不另做时间轴，先给一根年代脊柱：

1. **1920s 苏联**：维尔托夫把摄影机变成"电影眼睛"——纪录片开始意识到自己在选择。
2. **1930s 英国**：格里尔逊把纪录片变成公共事业，为国家与工业作证。
3. **1940s 二战**：宣传与见证同时成熟，纪录片第一次大规模进入战争。
4. **1960s 直接电影 / 真实电影**：轻便设备让摄影机可以跟着人走，旁观与参与分道。
5. **1980s 记忆转向**：《浩劫》之后，纪录片开始处理"不可再现"。
6. **2000s 以后**：院线化、流媒体、第一人称与参与式，纪录片重新变成公共事件。

## 一、美国

> 美国纪录片最擅长的，是**把制度拍成具体的人**：学校、工厂、法庭、竞选，都落到一张脸上。

| 片名 | 年代 | 它做了什么 |
|---|---|---|
| 《北方的纳努克》 | 1922 | 让"纪录长片"第一次成立，也让摆拍的伦理问题第一次出现 |
| 《不要回头》 | 1967 | 直接电影跟着鲍勃·迪伦巡演，把摄影机变成旁观者 |
| 《高中》 | 1968 | 怀斯曼用课堂与走廊展示制度如何塑造人 |
| 《推销员》 | 1969 | 跟着四个推销员跑完全程，让"美国梦"自己说话 |
| 《美国哈兰县》 | 1976 | 把摄影机交给罢工者，纪录片的立场第一次这么明确 |
| 《细细的蓝线》 | 1988 | 用重建镜头调查冤案，纪录片开始改写现实 |
| 《华氏 9/11》 | 2004 | 把政治纪录片送回院线，也把"主观"摆上台面 → [深解](../films/权力与政治-10-华氏911.md) |
| 《第四公民》 | 2014 | 用加密通讯拍斯诺登，纪录片参与正在发生的历史 |

> 关键词：**直接电影、观察、介入**。

## 二、英国

> 英国纪录片有两条线：一条为公共事业服务，一条替被遗忘的人作证。

| 片名 | 年代 | 它做了什么 |
|---|---|---|
| 《漂网渔船》 | 1929 | 格里尔逊把纪录片变成"公共事业" |
| 《夜邮》 | 1936 | 把邮政火车拍成一首工业诗 |
| 《倾听英国》 | 1942 | 战争年代不喊口号，只让日常的声音作证 |
| 《人生七年》 | 1964– | 用五十六年跟拍十四个人，把阶层拍成时间（系列） |
| 《走钢丝的人》 | 2008 | 用访谈与重现讲一次不可能的穿越 |
| 《艾米》 | 2015 | 用素材剪辑还原一个被观看毁掉的人 |

> 关键词：**公共记录、阶层、时间**。

## 三、法国

> 法国纪录片最特别的地方，是它一直不假装摄影机不存在。

| 片名 | 年代 | 它做了什么 |
|---|---|---|
| 《无粮的土地》 | 1933 | 布努埃尔把贫困拍成超现实的证词 |
| 《夜与雾》 | 1956 | 用克制的旁白与空镜，第一次让集中营以"记忆"的方式出现 |
| 《夏日纪事》 | 1961 | 鲁什让被拍者参与讨论"真实"，真实电影由此得名 |
| 《悲哀与怜悯》 | 1969 | 用口述拆开法国人对占领时期的神话 |
| 《浩劫》 | 1985 | 不用档案画面，只让幸存者说 → [深解](../films/战争与文明-09-浩劫.md) |
| 《拾穗者》 | 2000 | 瓦尔达把自己也拍进去，第一人称纪录片成熟 |
| 《迁徙的鸟》 | 2001 | 用摄影技术把自然拍成史诗 |
| 《脸庞，村庄》 | 2017 | 两个人一路贴巨幅肖像，把纪录片拍成相遇 |

> 关键词：**真实电影、记忆、第一人称**。

## 四、德国

> 德国纪录片始终绕不开一个问题：**影像如何参与制造历史，又如何清算历史。**

| 片名 | 年代 | 它做了什么 |
|---|---|---|
| 《柏林：城市交响曲》 | 1927 | 用一天的节奏把城市拍成交响乐 |
| 《意志的胜利》 | 1935 | 宣传片的教科书：让仪式与队列自己说话（只分析机制，不作美学推崇） |
| 《奥林匹亚》 | 1938 | 把体育拍成身体美学，也把意识形态藏进镜头语言 |
| 《德国之秋》 | 1978 | 多位导演合拍，用纪录片回应国家危机 |
| 《灰熊人》 | 2005 | 荷索用一个人拍下的素材，追问自然与疯狂 |

> 关键词：**宣传、罪责、档案**。

## 六、苏联 / 俄罗斯

> 苏联纪录片给世界留下的是两样东西：**剪辑的自觉**，和**档案的解剖**。

| 片名 | 年代 | 它做了什么 |
|---|---|---|
| 《持摄影机的人》 | 1929 | 摄影机第一次拍自己 → [深解](../films/影像基石-04-持摄影机的人.md) |
| 《列宁的三首歌》 | 1934 | 用歌声与字幕把政治宣传变成电影诗 |
| 《普通的法西斯》 | 1965 | 用档案素材解剖法西斯如何被日常地制造出来 |

> 关键词：**电影眼睛、蒙太奇、档案**。其余重要作品多为电视体系产物，不硬凑。

> 纪律：本表只给"它做了什么"的一句话判断，不展开影片分析；**纪录片的伦理争议（摆拍、重演、立场）只在必要处点一句，不替读者下结论。**
