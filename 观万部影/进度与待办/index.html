    第一轮已修的典型错误（供参考，说明审稿有效）¶

    • 《终结者》把《终结者2》的结尾旁白安到第一部

    • 《活着》家珍没有去世（结尾仍在饭桌上）

    第二轮的修复原则（重要）¶

    这一轮全是"只有断言、没有落到具体镜头"。铁律：手上没有影片，不许编镜头。

    两个选择，优先第二个： 1. 确凿记得某场戏 → 补上 2. 不确定 → 把断言收窄（"全片都是这样"→"有一场是这样"），或直接删掉立不住的漂亮话

    宁可这一节变薄，也不能变假。

    四、写作流水线的经验（已验证）¶

    模式 16 部耗时 token/部
    4 agent × 1 篇 258 秒 / 4 部 43.4k
    2 agent × 4 篇 753 秒 / 8 部 19.7k
    4 agent × 4 篇 377 秒 / 16 部 11.9k

    结论：一 agent 多篇更省 token，质量不衰减。 前提是每写完一篇立刻落盘——曾有两组 agent 中途 502，靠这条规则保住 14/16。
