    观万部影 · 200 部扩片草案（v2 · 按选片矩阵重做）¶

    状态：草案，待拍板。定稿后才动正文。 依据：观万部影-必看清单.md（125 部）的九类来源共识矩阵、豆瓣Top250-对照表.md、世界电影/世界电影-国别地图.md、导演/影史导演总表.md、电影史/电影史-时间轴.md。 逐部证据 → 观万部影-200部来源核实表.md（75 部逐条落到榜单 / 奖项 / 年份 / 教材坐标）。

    一、先修正上一版的方法错误¶

    v1 把 40 部问题轴全部取自豆瓣「留待 Level 2」，等于用一个来源替代了整个矩阵。豆瓣只是矩阵里的一格，而且它偏欧美、偏近三十年、偏情绪浓度。

    v2 的规则：

    1. 每部新片至少被两类来源支撑，并逐条标注；只有一类支撑的不收。
    2. 豆瓣不单独决定任何一部。它在表里的角色是"中文观众愿不愿意读"，不是"值不值得写"。
    3. 扩片先做矩阵缺口审计，缺哪一格补哪一格，而不是"豆瓣还剩多少部没选"。
    4. 125 部已有的片目不再重复计算；扩片只补空白与薄弱处。

    二、八类来源怎么用：角色、权重、证据档位¶

    榜单不是八张等权的票。它们回答的问题不同，用法也必须不同。

    来源 在选片中的角色 权重 必须带着看的局限
    Sight & Sound 十年评选 影史学术共识，基石层的第一主证 高 偏作者、偏西方艺术片；十年才更新一次，名单窄
    电影史教材（波德维尔等） 影史地位与技术语言节点的主证 高 滞后于创作，偏经典化作品
    戛纳 / 威尼斯 / 柏林最高奖 艺术电影共识，非西方作者的主要入口 高（仅最高奖） 评审偶然性大，获奖≠影史地位
    各国影史 / 国别权威榜 纠正好莱坞中心，非西方片的主证 高 榜单质量参差，语言门槛高
    AFI 百年百部 美国类型与工业经典的主证 中高（限美国片） 只覆盖美国，2010 年代后停更
    奥斯卡最佳影片 工业与时代共识，只作准主证 中 美国中心、公关影响大
    豆瓣 Top 250 可读性检验 + 华语/亚洲能见度，不作入选理由 中低（仅辅证） 偏欧美、偏近三十年、偏情绪浓度
    IMDb / Letterboxd 英语世界传播度，只用于排序 低（仅参考） 粉丝刷分、新片虚高

    证据三档¶

    • 主证：S&S 十年榜前列 / 教材专章 / 三大最高奖 / 国别权威榜前列 / AFI（限美国片）/ 奥斯卡最佳影片（限工业节点）。
    • 辅证：三大主竞赛入围与次级奖 / 奥斯卡提名与非表演类奖 / 豆瓣 Top250 / IMDb 与 Letterboxd 高分。
    • 参考：票房、流媒体热度、名次波动——只影响排序，不影响入选。

    五条裁决规则¶

    1. 1 主证 + 1 辅证，或 2 主证 → 可进 200。
    2. 只有辅证或参考 → 进 500 母库，不进 200。
    3. 豆瓣高但无主证 → 母库（如《忠犬八公》《怦然心动》）。
    4. 主证高但中文观众少 → 仍可进基石层，基石不为可读性服务（如《都灵之马》）。
    5. 三大获奖但影史地位一般 → 只算辅证，避免"获奖即经典"；同题多片竞争时，留"能提出不同问题"的那部，不留"更好看"的那部。
    6. 国别配额优先于单一榜单排名：非西方每个主要地区至少 1 部，再按主证补足。

    时效与复核¶

    S&S 十年一次、AFI 停更、豆瓣与 IMDb 每年波动、三大每年、教材按版本。 片单每两年复核一次；复核只换边缘片，不动基石层。

    本次扩片按此规则执行：40 部里 17 部豆瓣在榜（全部另有主证），23 部无豆瓣；无一部只有辅证。
