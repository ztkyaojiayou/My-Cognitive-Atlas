# My Cognitive Atlas · 个人认知体系

> 不是知识的仓库，而是**理解世界的操作系统**。

---

## 这是什么？

一个普通人试图系统地回答一个问题：

**"一个人如何理解自己、理解他人、理解社会、理解文明，并最终理解世界？"**

普通读书像往手机里下载很多 APP——但没有操作系统，APP 越多越乱。这个项目要做的是**安装操作系统**——一个面对复杂世界时，能定位问题、调用知识、比较视角、形成独立判断的认知框架。

---

## 核心理念

### 1. 从问题出发，而不是从书出发

入口永远是困惑——"人为什么孤独？""为什么社会是这样？""我为什么焦虑？"——而不是"今天读本哲学书"。书是回答问题的工具，不是目的。

### 2. 连接大于堆积

孤立的知识点没有意义。这个体系追求跨学科、跨学派的打通——同一问题，不同传统怎么回答？它们之间如何对话？形成思想网络，而非知识孤岛。

### 3. 呈现多元解释，而非唯一答案

对于价值问题、意义问题、解释问题，不存在"标准答案"。成熟的人不是没有观点，而是**知道自己的观点来自哪套解释体系，也知道其他体系为什么存在**。

---

## 五层系统架构

```
世界认知地图（问题树）      ← 入口永远是问题
        ↓
思想流派地图（解释框架）    ← 有哪些不同的答案？
        ↓
经典书籍库（节点资源）      ← 到哪里深入阅读？
        ↓
现实案例库（验证场景）      ← 怎么检验对不对？
        ↓
个人认知模型（自己的世界观） ← 我最终相信什么？
```

前三层是**输入**（理解世界），后两层是**输出**（形成判断）。

## 六大模块

```
                        认知体系构建
                             |
        -------------------------------------------------
        |        |        |        |        |        |
    读万卷书  观万部影  自我探索  行万里路  认知重构  常识百科
        |        |        |        |        |        |
      输入      输入      向内      向外      加工      基础
```

| 模块 | 定位 | 追问 |
|------|------|------|
| **[读万卷书](读万卷书/)** | 书的维度——经典逐本深度解读 | 这本书帮我们理解什么？ |
| **[观万部影](观万部影/)** | 影的维度——影像如何讲述人 | 这部电影让我感受到了什么？ |
| **[自我探索](自我探索/)** | 问题维度——从困惑出发的认知地图 | 我是谁？世界如何运行？ |
| **[行万里路](行万里路/)** | 实践维度——体验、验证、应用 | 真正去做时发生了什么？ |
| **[认知重构](认知重构/)** | 思考维度——连接、对比、内化 | 不同思想之间如何对话？ |
| **[常识百科](常识百科/)** | 工具维度——基础概念和框架 | 这个领域的基本逻辑是什么？ |

### 模块间的关系

- **读万卷书** 和 **观万部影** 是输入：提供思想的原材料
- **自我探索** 是导航：从困惑出发，调用多个输入来回答
- **认知重构** 是加工：把输入整合、对比、变成自己的东西
- **行万里路** 是验证：把认知放在现实中检验
- **常识百科** 是基础设施：不具备这些，其他模块的理解都会受限

## 出发点

这个项目始于与 ChatGPT 的一次对话——从深度解读弗洛姆的《爱的艺术》开始，意识到"读书"不该是收集知识点，而应该是**建立理解世界的坐标系**。

它不是给任何人看的"成果展示"，而是一个人在持续思考和成长的**工程记录**。
