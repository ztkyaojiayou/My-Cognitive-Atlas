    观万部影 · 三条辅轴草案¶

    状态：✅ 已定稿（2026-11-09），正文开写。 依据：观万部影-总纲草案.md 四/五/十节；观万部影-必看清单.md 125 部；进度见 进度与待办.md。

    一、要解决什么¶

    125 篇深解是 125 个点。每条都成立，但读者仍可能问：

    • 这部电影为什么偏偏出现在那个年代？
    • 不同文明在电影里最放不下的是什么？
    • 同一个导演，为什么一辈子在拍同一个问题？

    三条辅轴就是把这些点连成线：

    轴 方向 回答 目录
    电影史时间轴 纵向 它为什么在这个时间点出现？ 电影史/
    世界电影地图 横向 这个文明在电影里最爱讨论什么？ 世界电影/
    导演画像 作者 同一个作者反复在问什么？ 导演/

    原则：辅轴不是新增影评，是导航。 每一段都必须落回 films/ 里已完成的真实篇目，不引入 125 部之外的新片作为主线。

    三、三条轴的结构与体量¶

    3.1 电影史时间轴¶

    十个时代（沿用总纲第五节，补足代表片目与"留下什么"）：

    # 时代 核心变化 从 125 部中取的代表
    1 1895–1920s 默片 电影成为语言：蒙太奇、表现主义、纪录 持摄影机的人
    2 1930s–40s 好莱坞黄金 类型片成型、声音、战时宣传 公民凯恩 / 卡萨布兰卡 / 大独裁者
    3 1950s 战后现代主义 新现实主义、日本黄金期、作者意识 罗生门 / 东京物语 / 偷自行车的人 / 第七封印
    4 1960s 新浪潮 "电影应该是什么"、作者电影 四百击 / 八部半 / 2001
    5 1970s 新好莱坞 作者进入工业、黑色与暴力 教父 / 现代启示录 / 出租车司机
    6 1980s 商业大片 高概念、特效、香港黄金期 银翼杀手 / 终结者 / 龙猫 / 芙蓉镇
    7 1990s 独立与全球化 独立电影、华语崛起、类型融合 活着 / 霸王别姬 / 重庆森林 / 甜蜜蜜 / 肖申克的救赎
    8 2000s 数字电影 数字摄影、大片系列化、亚洲类型片 花样年华 / 一一 / 无间道 / 钢琴家
    9 2010s 流媒体 平台、超级英雄、韩国电影走向世界 寄生虫 / 燃烧 / 她 / 小丑
    10 2020s 算法与 AI 虚拟制作、分发算法、影像民主化 无依之地 / 隐入尘烟 / 宇宙探索编辑部

    每段固定四块：

    1. 时代问题（1–2 句，这段的人最怕什么、最想要什么）
    2. 技术与工业变化（3–5 条，只写确凿节点）
    3. 代表片目（3–5 部，链接到 films/；每部一句话说明"它为什么属于这个时代"）
    4. 这一段留下了什么（1 句，收在电影语言或人类经验上）

    体量： 10 段 × 700–800 字符 ≈ 7,000–8,000 字符（交付 7,956）。

    只写与 125 部能对上的节点；125 部覆盖不到的重要流派（如意大利西部片）最多一句带过，不展开成新篇。

    3.2 世界电影地图（国别/地区轴）¶

    十二个地区（总纲列了 14 个，非洲/拉美各只有 1 部入选，先并入"其他"或单列短节）：

    地区 最常讨论的问题 125 部中的代表
    美国 个人与自由：我能不能成为自己？ 教父 / 出租车司机 / 楚门的世界 / 肖申克的救赎
    日本 家庭、秩序与孤独 东京物语 / 罗生门 / 小偷家族 / 步履不停
    韩国 阶级与逃不开的位置 寄生虫 / 燃烧 / 杀人回忆 / 辩护人
    中国大陆 个人与时代 活着 / 霸王别姬 / 盲山 / 阳光灿烂的日子
    中国台湾 家庭、历史与成长 一一 / 牯岭街 / 悲情城市 / 饮食男女
    中国香港 城市、身份、速度、漂泊 花样年华 / 重庆森林 / 无间道 / 甜蜜蜜
    法国 爱情、思想、"电影是什么" 四百击 / 触不可及 / 这个杀手不太冷
    意大利 普通人的生活与美 偷自行车的人 / 八部半 / 美丽人生 / 天堂电影院
    德国 现代性、战争、罪责 帝国的毁灭 / 窃听风暴
    北欧 存在主义：上帝在哪？ 第七封印 / 野草莓
    印度 家庭 + 宗教 + 阶级 三傻大闹宝莱坞 / 摔跤吧！爸爸
    伊朗 在限制中用日常谈道德 一次别离 / 樱桃的滋味
    拉美 / 非洲 贫困、暴力、殖民与身份 上帝之城（短节）

    每区固定六块：

    1. 一句话电影传统
    2. 类型特长（这个地区最出名的电影类别：韩国的政治事件片、香港的功夫片、印度的歌舞片）+ 片单外的招牌（5–8 部不在 125 部的招牌代表作，片目少的地区不硬凑；只立桩、待补深解）
    3. 这个地区最常追问的 2–3 个问题
    4. 代表片目（链接 films/，2–4 部）
    5. 与相邻传统的对话（例如日本家庭片 vs 台湾家庭片 vs 伊朗家庭片）
    6. 一句话收尾

    体量： 12 区 × 700–900 字符 ≈ 8,000–11,000 字符（交付 10,645）。

    纪律：只写"这个地区的电影传统里常见什么主题"，不写国民性断言，不做"某国电影就是……"的整体判断。

    3.3 导演画像¶

    每位导演固定六块：

    1. 一句话作者签名（他一辈子在问什么）
    2. 时代位置（属于哪个运动/工业阶段）
    3. 反复出现的主题（3–4 个，每个配 125 部内的具体片目）
    4. 手法签名（镜头/剪辑/声音/色彩，只写确凿的）
    5. 代表作品（2–3 部，链接 films/）
    6. 一句话记住

    体量： 每位 1,100–1,600 字符；16 位 ≈ 18,000–26,000 字符（交付 20,268）。

    两份候选名单（见拍板点 Q1）：

    A. 经典作者轴 · 10 位（按影史地位与互补性）

    库布里克 / 黑泽明 / 小津安二郎 / 科波拉 / 斯科塞斯 / 王家卫 / 李安 / 杨德昌 / 贾樟柯 / 奉俊昊

    特点：覆盖默片后作者电影的主要坐标；代价是小津、斯科塞斯在本清单各只有 1 部（东京物语 / 出租车司机）。

    B. 片单密度轴 · 16 位（按 125 部中出现部数 ≥2 取全部）

    斯皮尔伯格（4）/ 诺兰、李安、王家卫、姜文、贾樟柯（3）/ 库布里克、黑泽明、科波拉、宫崎骏、伯格曼、奉俊昊、杨德昌、大卫·芬奇、卡梅隆、是枝裕和（2）

    特点：每一位都能在现有 125 篇里找到至少 2 部证据；出现 2 部的正好 10 位，全部收入，不做二次取舍。代价是漏掉小津、斯科塞斯、费里尼等"只有 1 部但极重要"的作者——这部分由同目录 导演/影史导演总表.md（228 位）补位。

    3.4 世界演员¶

    结构：按国别，年代作注解（2026-11-09 拍板）。

    • 17 个国别/地区节：美国 / 英国 / 法国 / 意大利 / 德国 / 北欧 / 苏联-俄罗斯 / 日本 / 中国大陆 / 中国台湾 / 中国香港 / 韩国 / 印度 / 伊朗 / 西班牙 / 拉美 / 非洲。
    • 每区 8–12 位（美国、英国、中国大陆、日本可到 15–20 位），不够不硬凑（伊朗 5、非洲 4）；每人一行：活跃年代 + 一句话表演签名 + 2–5 部代表作。
    • 跨时代演员只出现一次，年代写在行内，不按时代分组。
    • 体量：165 位 ≈ 11,200 字符。

    为什么不先分时代： 导演按时代，是因为"一部片属于哪个时代"有硬断代（工业、技术、流派）；演员跨三四十年是常态，硬塞进一个时代会失真，而"哪个国家的哪个演员"才是他被记住的方式。国别轴也与世界电影地图直接咬合。

    3.5 世界纪录片¶

    结构：按国别，年代作注解（2026-11-09 拍板）。

    • 16 个国别/地区节：美国 / 英国 / 法国 / 德国 / 北欧 / 苏联-俄罗斯 / 东欧 / 日本 / 中国大陆 / 中国台湾 / 韩国 / 印度 / 伊朗 / 拉美 / 非洲 / 大洋洲。
    • 每区 5–8 部；纪录片传统薄的地区 3–4 部，不硬凑。每部一行：片名 + 年代 + 它讲了什么 + 它为什么重要。
    • 收录口径：影史公认的纪录长片为主；影响极大的系列破例，行内标"（系列）"。
    • 开头给"纪录片六个节点"（1920s 维尔托夫 / 1930s 格里尔逊 / 1940s 二战 / 1960s 直接电影-真实电影 / 1980s 记忆转向 / 2000s 以后院线化与流媒体）。
    • 只给片单内 3 部挂真实深解链接（《持摄影机的人》《浩劫》《华氏 9/11》），其余立桩待补。
    • 体量：85 部 ≈ 9,000 字符。

    四、事实纪律（三条轴共用）¶

    1. 时间轴：只写确定的年份、流派、技术节点；不确定的"首创/第一次"一律不写。
    2. 国别：只解释电影传统与常见主题，不做国民性判断、不影射现实政治。
    3. 导演：生卒年、奖项、合作者不确定就不写；"作者签名"必须有本清单内作品作证据，不神化、不八卦。
    4. 链接不假：所有 films/ 链接必须指向真实文件；写完跑校验。
    5. 风格沿用"呼吸感"：短句、单行成段、每节 1–2 处加粗金句，不堆术语。

    五、校验方式¶

    新增 tools/verify_axes.py（或在现有脚本里加一段），检查：

    • 三条轴文件存在且标题结构齐全
    • 所有 films/xxx.md 链接文件真实存在
    • 每个时代/地区/导演的字符数落在约定区间
    • 代表片目名称与 films/ 文件名一致（防止"《xxx》"与文件片名对不上）

    收尾跑一次，再更新 观万部影/README.md 与 进度与待办.md。
