# 穿搭与形象 · 事实基线

> **卡片写作时只引用本文件，不自行生成硬事实。**
> 见 `../事实基线规范.md`。

---

## 一、本模块的头号禁令：**不写穿着建议**

- ❌「这样穿显高」「这个颜色衬肤色」「上宽下窄更显瘦」
- ❌ 任何搭配公式、比例口诀、场合穿搭方案
- ❌ 任何「什么值得买」
- ✅「合身指的是余量分布合理，不是紧——不同部位需要不同的余量」

**理由**：这类内容脱离你所在的场合、身体和偏好，就是无效信息；而且它们通常**先预设一个"应该长什么样"的标准**，再教你如何接近它。

> 判据：**把「你该怎么做」换成「这个判断在判断什么」，如果换完就不成立了，那就是建议。**

---

## 二、本模块的第二号禁令：**不做身材与性别的整体断言**

这是本模块最容易越界的地方。

- ❌「梨形身材适合 A 字裙」「小个子要避开长款」
- ❌「男生应该……」「职场上女性宜……」
- ❌ 任何**先给人分类、再给该类人推荐**的句式
- ✅「服装的版型有一套给定的尺寸关系，而人的身体尺寸分布是连续的——**两者对不上是常态**」

**判据：凡是要先把人分成几类才能说的话，这里都不说。**

> 原因不只是"避免冒犯"。**这类分类本身把"标准身体"当成了默认值**，然后把偏离它的人定义为需要修正的一方。这不是事实判断的问题，是框架的问题。

---

## 三、本模块的第三号禁令：**不推荐品牌，不写价格**

- ❌ 任何品牌、产品的推荐与评价
- ❌ 任何价格、性价比
- ❌ 对"快时尚""奢侈品牌""设计师品牌"整体的褒贬
- ❌ 流行趋势的预测（"今年流行……"）

---

## 四、本模块的第四号禁令：**不把便利说法当学术事实**

| 常见说法 | 实际成立情况 |
|---|---|
| **「支数越高越好」** | 支数反映纱线细度，**口径在不同体系里不一致**。高支更细腻，但强度往往下降、更娇气。它是参数，不是等级 |
| **「纯天然一定比化纤好」** | 天然与合成本身不是优劣。**合成纤维在强度、快干、弹性上有天然纤维做不到的地方**；天然纤维在吸湿、透气、亲肤上通常更优。要看用途 |
| **「这个颜色衬肤色」** | "衬肤色"缺少可核验的标准，**且它默认有一套应当被"衬"的肤色**。可以讲颜色之间、颜色与明度的关系，**不要写"什么人适合什么色"** |
| **「贵是因为面料好」** | 面料只是一部分。**工序数量、版型开发、质检、库存与渠道都算在成本里**，售价里还有品牌溢价 |
| **「同一个码数就是同一个尺寸」** | **各国的号型标准不同，各品牌的放量也不同**；还有为适应心理而放宽标注的做法。同码不同尺寸是常态 |

> 判据：**一句话如果"行业里也没有统一口径"，就不能写成"事实上是"。**

## 五、可写的概念与机制（白名单）

### 5.1 衣服在传递什么

| 概念 | 可写内容 |
|---|---|
| **三层结构** | **功能**（挡风、透气、耐磨、好活动）、**社会**（场合、身份、尊重与否）、**个人**（希望被怎样看待）。三者**经常冲突** |
| 冲突的典型形态 | 一件很好看的衣服可能不适合久站；最舒服的搭配可能不适合某个场合；完全符合场合的一套，可能完全不像你 |
| 它为什么是"系统" | 因为它同时携带多种信息，而接收方会**同时解读**。所以你无法只发送其中一层 |
| **服装编码** | 每一类场合都有一套惯例，它规定了某些元素可以/不可以出现。这套编码**不是明文规定，是被共同默认为的** |

### 5.2 面料

| 概念 | 可写内容 |
|---|---|
| 纤维的三大来源 | **天然纤维**（棉、麻、羊毛、丝）、**再生纤维**（从天然原料加工而来，如粘胶、莱赛尔）、**合成纤维**（涤纶、锦纶、腈纶、氨纶） |
| 它们各自擅长什么 | **棉**：吸湿、亲肤，但干得慢、易皱。**麻**：透气、挺括，但易皱。**羊毛**：保暖、吸湿、有弹性。**丝**：轻薄、光泽，但娇气。**涤纶**：强度高、快干、不易皱，常规产品透气性较差。**氨纶**：提供弹性，通常少量混入 |
| **"天然 vs 合成"不是优劣** | 合成纤维在强度、快干、弹性上有天然纤维做不到的地方。**看用途，不看来源** |
| **织法比纤维更影响手感** | **梭织**（经纱与纬纱垂直交织）结构稳定、弹性小；**针织**（线圈串套）有弹性、贴合。**同一根纱，两种织法出来是两种东西** |
| 纱线细度 | 通常用"支数"表达。**口径在不同体系里不一致**；高支更细腻，但强度往往下降 |
| **后整理** | 染色、预缩、防水、抗皱、柔软整理等。**它改善性能，也可能带来化学负担**——这是真实存在的取舍 |
| 它的代价 | 追求挺括常靠后整理，代价是手感与透气性；追求柔软常牺牲形态稳定性。**每一项性能提升都可能削弱另一项** |

### 5.3 版型与合身

| 概念 | 可写内容 |
|---|---|
| 版型是什么 | 各部位的尺寸关系：肩线、袖窿、领围、胸腰臀围、下摆。**它是一组比例，不是一张图片** |
| **"合身"的准确含义** | **余量分布合理**，不是紧。不同部位需要不同的余量——肩要贴合，腰腹要留活动空间，坐下时不能绷 |
| 为什么合身比好看更基础 | 版型不对会持续产生干扰：肩线错位会拉扯整件衣服，袖窿过小会限制手臂活动。**这些不解决，其他都谈不上** |
| **版型与身体的错配是常态** | 成衣是按若干标准尺码生产的，而人的身体尺寸是连续的。**对不上是必然，不是谁的问题** |
| 修改的价值与限制 | 改衣能调整长度、腰围、袖长等；**但涉及肩线、袖窿这类结构的改动成本很高**，常常不划算。这是"合身"在成衣体系里难以普遍实现的原因之一 |

### 5.4 颜色

| 概念 | 可写内容 |
|---|---|
| 三个基本维度 | **色相**（红黄蓝等）、**明度**（明暗）、**饱和度**（鲜艳程度）。**"颜色搭不搭"的多数讨论，其实是在说明度与饱和度的关系** |
| 搭配的几种关系 | **同色系**（同一色相不同明度）、**邻近色**、**对比色**、**互补色**。它们没有优劣，是四种不同的效果 |
| **为什么有的"配"有的"不配"** | 多数情况不是色相冲突，是**明度或饱和度太接近反而打架**，或者**整体没有一个主次**。这是可分析的关系，不是天赋 |
| 光的影响 | 同样的颜色在不同光源下看起来不同。**这是"在店里好看回家不好看"的常见原因** |
| **关于"衬肤色"** | **本模块不写"什么人适合什么色"。** 可以说的是：颜色与肤色之间是一种**对比关系**（明度差、饱和度差），对比强弱会改变观感——**但"应该显得怎样"是一个审美偏好，不是一个事实** |
| 它的代价 | 强调对比会显得有精神，代价是不容易协调；强调统一会显得整体，代价是平淡。**这是取向** |

### 5.5 场合与着装规范

| 概念 | 可写内容 |
|---|---|
| 着装规范是什么 | 一套关于某类场合该穿什么的**共识性约定**。它在不同地区、不同行业差异很大，且**一直在变** |
| 它的功能 | **降低不确定性**：不知道该穿什么的时候，规范给了答案。同时它也在**标示场合的性质**——正式与非正式，靠这套编码区分 |
| **它为什么不是"形式主义"** | 因为它承担的是**沟通功能**：穿得合适，是在说"我知道这是什么场合"。**这套信号之所以有效，是因为它有成本**——随意的穿着无法传递这个信息 |
| **它的代价** | 规范会排除掉一部分人——**他们的身体、预算、或文化背景使他们难以符合那套编码**。这不一定是恶意，但它是真实的排斥 |
| 它的变化 | 随着行业、代际与工作方式变化，规范在持续松动或迁移。**看起来古老的东西，往往几十年前才定型** |

### 5.6 制造与价格

| 概念 | 可写内容 |
|---|---|
| 链条的环节 | 设计 → 打样 → 采购面料 → 裁剪 → 缝制 → 水洗整理 → 质检 → 分销。**每个环节都有损耗与人工** |
| **工序数量是关键变量** | 一件衣服可能有几十到上百道工序。**走线、锁边、里布、扣眼的处理，直接决定它穿一年后是什么样**——而这些在标签上看不出来 |
| 成本构成 | 面料、辅料、人工、物流、关税、库存风险。**加价里还有品牌、渠道与设计投入**。所以"贵"≠"料好" |
| 全球分工 | 面料、辅料、缝制常常分布在不同的地方。**同一个工厂可以同时为不同定位的品牌生产**——这解释了为什么"便宜的那件和贵的那件看起来一样" |
| 它的代价 | 分工越细，品质越依赖**质检这一环**；而质检的成本压力最大，最容易被压缩 |

### 5.7 快时尚

| 概念 | 可写内容 |
|---|---|
| 它改变了什么 | **从设计到上架的周期被大幅缩短**，款式的更新频率加快。这本身是供应链能力的进步 |
| 实现方式 | 小批量多款式、快速返单、就近或快速响应的产能。**核心是"反应速度"，不是"便宜"本身** |
| **代价落在哪** | 三个方面：**人工**（赶工期）、**材料**（成本压缩到面料上）、**环境**（用水、化学品、废弃）。而这三处**都不在消费者的视线里** |
| 一个常见的错觉 | 以为"便宜"来自规模效应。**规模只是一个来源，另一个来源是把成本转移到看不见的地方** |
| 它的边界 | 这个模块**不评价买快时尚这件事本身**。它讲的是这套系统的运作方式与代价落在哪——**买或不买是各人的判断** |

### 5.8 品牌与尺码

| 概念 | 可写内容 |
|---|---|
| 品牌在卖什么 | 三样：**识别**（让人一眼知道这是什么）、**一致性**（同一品牌的东西品质稳定）、**符号**（它代表什么）。**溢价来自这三样，不完全来自产品** |
| 品牌与生产的关系 | 品牌常常并不自己生产。**"设计—生产—销售"可以完全分离**，这也意味着品牌价值与产品价值不是一回事 |
| 它的代价 | 符号价值会随人群变化而波动，**所以依靠符号的品牌需要持续投入维持它** |
| **尺码为什么不准** | 三个原因：**各国号型标准不同**；**各品牌的放量不同**（哪怕源自同一标准）；以及**为适应心理而放宽标注**（同一个实际尺寸被标成更小的码） |
| 它的后果 | "我穿多大码"这句话**离开具体品牌就没有意义**。这不是你的问题，是这套体系的性质 |
| 测量的影响 | 同一件衣服，平铺量与穿着量不同；不同部位的测量方法也可能不同。**所以尺码表只能作为参照** |

### 5.9 个人风格

| 概念 | 可写内容 |
|---|---|
| 它不是天赋 | 风格是**反复选择之后被看出来的模式**：你总是选什么、总是回避什么、愿意为哪一类东西多花一点 |
| 它受什么限制 | 身体条件、场合要求、预算、可获得的选择（尺码范围、地域、渠道）。**"自由表达"发生在一个被限制的空间里** |
| 它为什么需要时间 | 因为模式需要足够多的选择次数才能显形。**一两次尝试看不出风格，只能看出偏好** |
| 一个反直觉的点 | **风格不是"找到的"，是"积累出来的"。**所以"先想清楚自己是什么风格再买"这个顺序，其实是反的 |
| 它的代价 | 有清晰风格意味着**选择范围变窄**——很多明明不错的东西会被自然地排除。**这是效率，也是局限** |

## 六、易混概念对照（本模块最值钱的一组）

| 常被混淆 | 区别 |
|---|---|
| **合身 vs 紧** | 合身是余量分布合理，紧是整体余量不足 |
| **纤维 vs 织法** | 前者是原料，后者是结构。**同一根纱，织法不同就是两种面料** |
| **天然 vs 更好** | 两个不同的判断。合成纤维在强度、快干、弹性上有天然纤维做不到的 |
| **风格 vs 流行** | 前者是自己反复选出来的模式，后者是外部给出的选项集 |
| **品牌价值 vs 产品价值** | 可以分离。同一个工厂可能同时生产不同定位的产品 |
| **贵 vs 料好** | 成本里还有工序、开发、质检、库存与渠道；售价里还有品牌溢价 |
| **尺码 vs 尺寸** | 前者是标签，后者是实测。两者在不同品牌之间对不上是常态 |
| **着装规范 vs 形式主义** | 前者承担沟通功能，它的信号之所以有效，是因为符合它有成本 |
| **"衬肤色"vs 对比关系** | 前者是审美判断，后者是可描述的关系。本模块只讲后者 |
| **风格 vs 好看** | 前者是"这是你"，后者是"这符合某个标准"。两者不必一致 |
| **快时尚 vs 便宜** | 核心是供应链的反应速度，便宜是结果之一，且代价被转移到看不见的地方 |

## 七、本模块「不确定就别写」清单

**以下一律不写：**

- ❌ 任何穿着建议、搭配方案、比例口诀
- ❌ 任何身材分类与"适合什么"的建议
- ❌ 任何性别整体断言
- ❌ 任何品牌、产品、价格的推荐与评价
- ❌ 流行趋势的预测
- ❌ 「什么颜色衬什么肤色」式判断
- ❌ 具体的工艺参数与成本数值
- ❌ 对"买不买快时尚"的道德判断
- ❌ 任何关于身材、容貌的评价性表述

> ⚠️ **本模块最容易滑向的地方**：写着写着变成了穿搭指南。
> **一旦出现"这样穿会显得……"，这张卡就已经不在讲结构了。**

## 八、写作提醒

1. **每讲一件衣服的特征，先说它是哪一环决定的**：纤维、织法、版型、工序，还是品牌。
2. **把"标准"和"身体"分开。** 版型是一组给定的尺寸关系，而人的身体是连续的——**对不上是体系的常态，不是谁的问题。**
3. **不预设一个"应该长什么样"。** 这是本模块最容易犯、也最伤人的一个错。
4. **不评价消费选择。** 讲清代价落在哪，买不买是各人的事。
5. **与 `27-经济与金融素养` 分工**：那边讲价格与市场，这边讲产品本身。

## 九、资料来源分级（本模块）

| 级别 | 对应 |
|---|---|
| A | 纺织与服装工程的教科书、号型标准的规范文本、供应链的行业研究 |
| B | 通行服装史与产业读物、有编辑把关的专业媒体 |
| C | 优质时尚写作、纪录片 |
| D | 穿搭博主、种草笔记、品牌软文 | → **本模块危害最大，一律不作依据** |

> 这个模块的 D 级内容有一个特征：**它把"某类身体"当成了默认前提，再教你怎么向它靠拢。**
> 判断的办法不是看它说得有没有道理，是问：**它假设你长什么样？**
